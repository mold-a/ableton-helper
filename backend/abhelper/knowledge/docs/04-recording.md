# Запись MIDI и аудио: arm, overdub, метроном, Capture MIDI
keywords: запись, record, recording, arm, армить, overdub, овердаб, метроном, metronome, count-in, отсчёт, capture midi, захват миди, record quantization, квантование записи, session record, arrangement record, loop recording, как записать, записать вокал, записать midi клавиатуру, punch in, punch-in, punch out, режим записи

## Подготовка к записи
1. Выберите или создайте дорожку нужного типа (MIDI для нот, аудио для вокала/гитары).
2. Включите **Arm** (круглая кнопка внизу дорожки) — дорожка готова принимать сигнал. В настройках Live можно включить «Exclusive Arm» (одна armed-дорожка за раз).
3. Для аудио: в «Audio From» выберите вход (Ext. In → нужный канал вашей аудиокарты). Нужные входы включаются в Settings (Preferences) → Audio → Input Config.
4. Для MIDI: убедитесь, что клавиатура включена в Settings → Link, Tempo & MIDI → MIDI Ports (столбец Track = On для вашего входа).
5. Проверьте, что вы слышите вход: Monitor = Auto или In.

## Запись в Arrangement
1. Включите arm на дорожке.
2. Установите курсор вставки в нужное место на временной шкале.
3. Нажмите кнопку **Arrangement Record** (круглая кнопка в Control Bar), затем Play, или просто Record — запись начнётся с текущей позиции.
4. Остановите запись пробелом.
Запись происходит поверх существующего содержимого в выбранных дорожках, поэтому для безопасной записи создайте новую дорожку.

## Запись в Session (клип-слот)
1. Включите arm на дорожке.
2. Нажмите круглую кнопку в пустом слоте клипа — начнётся запись нового клипа. Повторное нажатие переключает на проигрывание.
3. Кнопка **Session Record** в Control Bar записывает в следующий свободный слот.
Длину нового клипа можно задать заранее (Record Length / «New Clip Length» в настройках Record/Warp/Launch) или закончить вручную.

## Overdub (дозапись MIDI)
- Кнопка **MIDI Arrangement Overdub** (значок «+» около Record) включает дозапись нот поверх уже записанных, не стирая старые.
- В Session аналогичная кнопка — **Session Overdub**.
- Для петель: включите Loop (кнопка петли в Control Bar), и каждый круг добавляет новые ноты.

## Метроном и отсчёт (Count-in)
- Кнопка метронома находится в Control Bar. Выпадающее меню рядом с ним содержит **Count-In** (None / 1 Bar / 2 Bars / 4 Bars) и настройки звука метронома.
- Метроном можно отключить на время записи (Only While Recording / Only While Playing в выпадающем меню).

## Capture MIDI (захват MIDI)
Если вы играли на MIDI-клавиатуре при выключенной записи (при armed MIDI-дорожке), Live «помнит» сыгранные ноты. Нажмите **Capture MIDI** (кнопка в Control Bar / меню Create), чтобы превратить сыгранное в клип.
Подходит, когда вы импровизировали и забыли нажать Record.
Live 10 и новее поддерживают Capture MIDI; точное расположение кнопки зависит от версии.

## Квантование при записи (Record Quantization)
- Меню Edit → **Record Quantization** позволяет автоматически подтягивать ноты к сетке во время записи.
- Задайте значение (например, 1/16) или None, чтобы сохранить живую игру.
- Позже можно квантовать записанный клип в Clip View: **Cmd/Ctrl+U**. Подробнее: тема «Редактирование MIDI».

## Запись аудио: полезные советы
- Выставьте уровень входа: пик не должен достигать 0 dB (красного); оптимально около −12…−6 dB.
- Уменьшите размер буфера (Settings → Audio → Buffer Size) для записи, чтобы снизить задержку; для микса верните побольше.
- Для записи без задержки используйте мониторинг через аудиокарту (Direct Monitoring) и Monitor = Off.
- Задержка записи (latency) компенсируется Live автоматически, но при необходимости настраивается в разделе Audio настроек (Driver Error Compensation).

## Punch-in / Punch-out
В Arrangement можно включить кнопки Punch-In/Punch-Out в Control Bar, чтобы запись шла только внутри выделенного отрезка. Вместе с петлёй это удобно для перезаписи ошибок.

## Если запись не идёт
- Дорожка не в arm → включите кнопку Arm.
- Нет входного сигнала → проверьте Audio From/MIDI From и Input Config.
- Ноты записываются, но звука нет → на MIDI-дорожке нет инструмента; перетащите инструмент из браузера.
См. также «Типичные проблемы».
