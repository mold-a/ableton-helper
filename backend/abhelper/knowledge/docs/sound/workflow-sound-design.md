# Процедура саунд-дизайна: как создавать и править звук в Live
keywords: как сделать звук, процедура, workflow, пошагово, sound design, саунд-дизайн, создать звук, хочу звук, подобрать устройство, get_device_parameters, display, единицы, gain staging, запас по уровню, итерация, прослушать, по одному параметру, ошибки, чек-лист, tweak, правка звука

## Порядок действий для нового звука
1. Определите физику цели: чем возбуждается звук (дыхание, смычок, щипок, удар, свободный язычок, электроника), какой у него спектр (все гармоники — пила; только нечётные — квадрат/кларнет; негармоничный — колокол/пластины), как течёт во времени (непрерывный — Sustain 1.0; затухающий — Sustain 0 и Decay), есть ли вибрато/тремоло, форманты корпуса, один инструмент или секция. 2. Выберите устройство (раздел ниже). 3. Осцилляторы: волна, октавы, уровни, расстройка. 4. Фильтр: тип, срез, резонанс, слежение за клавишей. 5. Огибающие громкости и фильтра. 6. Модуляция: вибрато, тремоло, LFO-движение. 7. Эффекты по порядку: EQ → насыщение → компрессор → модуляция (хорус, только если нужен) → delay → reverb → Utility. 8. Настройка уровней (gain staging). 9. Прослушайте тестовые ноты, внесите правки по одной-трём за шаг. Если рецепт для запрошенного инструмента уже есть в библиотеке проекта — стартуйте с него, а не с пустого устройства.

## Выбор устройства
Operator — аддитивные и FM-звуки, у каждого осциллятора своя огибающая: язычковые, органы, щипки, мэллеты, колокола, электропиано, 808. Analog — классический вычитающий синтез, два независимых канала (OSC→фильтр→усилитель): медь, струнные, пэды, лиды, басы; хорошие унисон и вибрато. Drift — быстрый тёплый аналоговый звук с естественной «плавающей» нестабильностью (пэды, басы, живые язычковые). Wavetable — современные пэды, лиды, цифровые текстуры; сама таблица, режим эффектов и унисона по API не выбираются, пользуйтесь пресетом из браузера. Simpler — сэмплы: реализм акустических инструментов, любые сэмплы пользователя; без сэмпла молчит. Drum Rack — кит ударных (выбирают пресет из браузера и правят цепочки). Corpus — резонанс корпуса поверх синтеза. Правило: акустика с затуханием по частотам — Operator; нужен унисон/вибрато/классический фильтр — Analog; быстро «тёплое» — Drift; максимальный реализм — Simpler с сэмплами.

## Как читать get_device_parameters
Каждый параметр приходит с именем (использовать нужно точное), min/max, default, value_items (для переключателей и списков) и текущим display-значением (то, что показывает Live: «5.5 kHz», «28 ms», «−6 dB», «35 %»). Большинство нелинейных параметров нормировано 0…1 (Filter Freq, Attack, Decay…); min/max в сыром виде в таком случае не говорит о единицах — задавайте их через display-строку: `{"display": "1.3 kHz"}`; если display не принимается, используйте `{"norm": 0..1}` и сразу перечитайте результат. Некоторые параметры уже в естественных единицах (Saturator Drive −36…36 dB, Compressor Output Gain −36…36 dB, Operator Transpose ±48, Filt < Key −200…200 %); значения списков передавайте именем («Saw 32», «Alg. 11», «Lowpass»). Число рядом с `A Coarse` — это отношение частот (0 → ×0.5), а не полутона. После установки всегда проверяйте фактический display: если он не совпал, значение не принято или ограничено диапазоном.

## Почему менять мало параметров за шаг
Звук — система связанных параметров: яркость зависит от среза, резонанса, формы волны, насыщения и EQ одновременно. Если за раз изменить десять параметров, невозможно понять, что помогло, а что навредило; оценка на слух искажается из-за изменения громкости. Меняйте 1–3 параметра за шаг, одной «группы» (например, срез + Fe Amount), и сразу слушайте. Размер шага — по таблице: срез ×1.5–2, атака ×3–6, реверб ±8–10 %, EQ ±1.5–3 dB, уровень осциллятора ±3 dB, расстройка ±2–5 ct. Если результат хуже — откатите именно этот шаг. Ведите список изменений (было → стало), чтобы вернуться к рабочему состоянию. Просьбы вроде «ярче» выполняйте минимально достаточным шагом и спрашивайте, достаточно ли; для крупного перелома тембра (например, из пилы в квадрат) делайте это отдельным шагом.

## Gain staging: уровни
Сумма осцилляторов в Operator легко превышает 0 dB (четыре осциллятора по −2 dB дают +4 dB): ставьте Volume инструмента около −6 dB и проверяйте пики. Цель: пики на выходе инструмента −12…−6 dBFS, после эффектов — не выше −6 dBFS, на мастере −6…−3 dBFS перед мастерингом. Эффекты, меняющие громкость, компенсируйте: Saturator Output ≈ −(Drive/2), Compressor Makeup/Output Gain, EQ Eight Output Gain, Reverb не должен поднимать общий уровень. Utility Gain ставьте в конце как «громкость канала». Всегда сравнивайте «до/после» при одинаковой громкости. Не «лечите» громкость мастером. Низ: High Pass 25–30 Hz на всём, кроме суб-баса и 808; ниже 120–150 Hz — моно.

## Прослушивание и итерации
Тест для любого инструмента: ноты в трёх регистрах (низ C2, середина C3–C4, верх C5–C6), аккорд, повтор одной ноты, легато-фраза, разные velocity (40, 80, 120), длинная нота и Note Off (проверьте release). Слушайте по критериям: атака (клик/мягкая), спектр (острота/тусклость), сустейн (постоянство/затухание), релиз (хвост), движение (биение, вибрато), шум, баланс по высоте (низкие тусклые, верхние резкие?), моно-совместимость. Сверяйтесь с описанием цели: какой должна быть яркость, есть ли вибрато, как быстро затухает. Итерация: изменение → прослушивание → сравнение с прошлой версией → принять/откатить. После трёх-пяти итераций остановитесь и спросите пользователя, приближается ли звук к желаемому; если нет — смените подход (другой осциллятор/устройство/сэмпл), а не продолжайте тонко подкручивать.

## Типовые ошибки новичка и ИИ
(1) Предположили нейтральные «по умолчанию»: у Operator B/C/D Level = 0, Filter On с Freq посередине; у Analog AEG Sustain = 0 (нота гаснет); у Wavetable Filter Freq ≈ открыт; у Simpler нет сэмпла. (2) Забыли включить осциллятор или нужный Algorithm (Alg. 11 для аддитивных). (3) Путали Coarse (отношение частот) и полутоны. (4) Слишком высокий резонанс (>0.5) — звон/самоосцилляция. (5) Хорус и Spread на соло-инструментах. (6) Тройное затемнение: фильтр + EQ-полка + HiFilter реверба. (7) Реверб слишком длинный/мокрый (>25 % на соло). (8) Перегруз от суммы осцилляторов и Saturator. (9) Один и тот же параметр правят в нескольких местах (фильтр инструмента и Auto Filter). (10) Правят EQ, чтобы исправить то, что нужно менять в оригинале (форма волны, огибающая). (11) Меняют несколько параметров одновременно и не помнят, что помогло. (12) Для высоких нот не используют Time < Key/Filt < Key.

## Правки по запросу: с чего начинать
Выберите, где решается задача: тембр (форма волны, гармоники, фильтр инструмента), баланс частот (EQ Eight), огибающая (Attack/Decay/Release в инструменте), пространство (Reverb, Delay), динамика (Compressor, velocity-зависимости), ширина (Spread, Utility, Unison), характер (Saturator, Overdrive, Redux). Прочтите текущее состояние, откройте adjectives.md для конкретной просьбы, примените один шаг, прослушайте. Если пользователь пожаловался на «синтетичность» — сначала проверьте физику (нет ли лишнего хоруса/унисона, есть ли щелчок атаки и связь яркость–громкость), и только потом EQ. Если запрос выходит за возможности синтеза (реалистичный баян, скрипка соло) — честно предложите сэмплы (Simpler) или слой «сэмпл + синтез» и скажите, что именно синтез не передаст.
