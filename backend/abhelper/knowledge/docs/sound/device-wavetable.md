# Wavetable: гид по синтезатору (Live 11.3.25)
keywords: wavetable, вейвтейбл, волновая таблица, osc 1 pos, position, sub, filter 1, amp attack, env 2, lfo, unison amount, matrix, матрица модуляции, effect 1, effect 2, fm, warp, fold, современный пэд, лид

## Wavetable: сигнальный путь и ограничения API
Wavetable — два осциллятора на волновых таблицах (Osc 1, Osc 2) плюс Sub-осциллятор, два фильтра, три огибающих (Amp, Env 2, Env 3), два LFO и матрица модуляции. Главное ограничение работы через API: ни сама волновая таблица, ни режим эффектов осциллятора (FM / Classic / Modern), ни режим унисона и число его голосов, ни источники и цели матрицы по параметрам Live не выбираются. Что реально меняется: Osc 1 Pos / Osc 2 Pos (положение в таблице), Osc Effect 1 / Effect 2 (два слайдера, смысл зависит от выбранного режима), Transp и Detune, Gain, Pan, Sub, фильтры, огибающие, LFO, Unison Amount, Global Mod Amount, Time, Glide, Transpose, Volume. Поэтому надёжная стратегия: загрузить из браузера подходящий пресет (pad, lead, bass, pluck…), затем править параметры. Строить с нуля нужный тембр акустического инструмента Wavetable не подходит — для этого Operator, Analog или Drift. Хорош для современных пэдов, лидов, цифровых текстур.

## Wavetable: осцилляторы и Sub
Osc 1 On / Osc 2 On; Osc 1 Transp (−24…24 полутона, сдвиг относительно ноты); Osc 1 Detune (0.5 — ноль, в центах); Osc 1 Pos (0…1) — положение в таблице: разные позиции дают разные формы волны, при движении меняется тембр; Osc 1 Effect 1 / Effect 2 — режимо-зависимые: в FM — Amt и Tune (глубина и расстройка внутренней модуляции: ±50 % = октава, значения между дают негармоничность), в Classic — PW и Sync, в Modern — Warp и Fold (дополнительные гармоники); Osc 1 Pan; Osc 1 Gain. Sub On, Sub Tone (0 = чистый синус, больше — добавляет гармоник), Sub Gain, Sub Transpose (0, −1, −2 октавы). Типично: Osc 1 Gain 0.8–1, Osc 2 Gain 0.5–0.7 с детюном 5–15 ct, Sub Gain 0.3–0.5 для баса. Осцилляторы без модуляции не дают алиасинга.

## Wavetable: фильтры
Filter 1 On, Filter 1 Type: Lowpass, Highpass, Bandpass, Notch, Morph; Filter 1 LP/HP (схема: Clean, OSR, MS2, SMP, PRD); Filter 1 BP/NO/Morph (Clean, OSR); Filter 1 Slope: 12 или 24 dB; Filter 1 Freq (0…1, нелинейно — используйте display, «2.5 kHz»), Filter 1 Res, Filter 1 Drive (работает не на Clean), Filter 1 Morph. Filter 2 устроен так же и по умолчанию выключен. Режим соединения фильтров (Serial/Parallel/Split) через API недоступен. Практика: значения Freq по умолчанию (≈ 0.9966) — фильтр практически открыт; для тёмного пэда опускайте Filter 1 Freq до 800 Hz–2 kHz, для лида 4–8 kHz; резонанс держите до 0.3, чтобы не звенело. Источники модуляции частоты фильтра (Env 2, LFO) зависят от пресета; если нужна огибающая фильтра, берите пресет, где она уже назначена, и меняйте Env 2 Attack/Decay/Sustain/Release.

## Wavetable: огибающие и LFO
Amp Attack / Decay / Sustain / Release — огибающая громкости (0…1, нелинейно; используйте display: «15 ms», «800 ms»). Amp Sustain по умолчанию ≈ 0.71. Slope-параметры (Amp A Slope, D Slope, R Slope) задают кривую: >0.5 быстрый старт, <0.5 медленный старт. Amp Loop Mode: None, Trigger, Loop. Env 2 и Env 3 дополнительно имеют Initial, Peak, Final. LFO 1 / LFO 2: Shape (Sine, Triangle, Sawtooth, Rectangle, Noise), Amount, Rate или S. Rate (при Sync = Tempo), Retrigger, Attack Time (плавный вход вибрато), Phase Offset. Global Mod Amount — общий множитель всех модуляций матрицы (0.5 — по умолчанию), Time — общий масштаб скоростей модуляторов. Unison Amount (0…1) — сила унисона; режим и число голосов задаёт пресет. Для расширения пэда поднимайте Unison Amount до 0.3–0.5; для баса и лидов в моно — ниже 0.2.
