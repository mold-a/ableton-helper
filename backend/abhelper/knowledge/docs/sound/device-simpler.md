# Simpler: сэмплер Live (Live 11.3.25)
keywords: simpler, симплер, сэмплер, sampler, sample, сэмпл, loop, луп, one-shot, classic, slicing, нарезка, start, length, fade, sample selector, ve attack, filter freq, spread, transpose, detune, реалистичный инструмент, мультисэмпл

## Simpler: что это и главное условие
Simpler проигрывает один сэмпл по MIDI-нотам: сэмпл → (Start/Length/Loop) → Filter → Pan/Spread → Volume с огибающими Ve (громкость), Fe (фильтр), Pe (питч) и LFO. Главное: без загруженного сэмпла Simpler молчит — по API нельзя «синтезировать» звук в пустом Simpler; сэмпл нужно взять из браузера Live (пресет Simpler/Sampler с сэмплами, например инструменты из Packs или Core Library) или перетащить файл. Сэмпл звучит в исходной высоте на C3 (MIDI 60). Режим воспроизведения (Classic — полифония, ADSR, лупы; One-Shot — моно, проигрывает целиком; Slicing — нарезка на ноты) переключается в интерфейсе; параметра режима в списке API нет, зато доступны Trigger Mode (Trigger/Gate), Ve Loop, Fade In, Fade Out. Если пользователь просит реалистичный акустический инструмент (баян, рояль, скрипка), лучший путь — сэмплированный пресет из браузера, а не синтез с нуля.

## Simpler: параметры сэмпла и высоты
S Start (0…1) — начало воспроизведения внутри региона (сдвиг к 0.02–0.1 убирает мёртвый тишинный/дыхательный старт), S Length — длина региона, S Loop On и S Loop Length (доля региона в петле), S Loop Fade (кроссфейд на стыке петли — убирает щелчок; 0.05–0.2 для звучащих инструментов). Snap (On) — привязка границ к нулевым переходам. Sample Selector (0…127) выбирает сэмпл в мультисэмпловых зонах (по документации это функция Sampler; в Simpler параметр присутствует в списке, но его эффект не подтверждён — не полагайтесь). Transpose (−48…48 st) и Detune (−50…50 ct) — высота; Glide Mode: Off, Portamento, Glide; Glide Time; Spread (0…100) — два расстроенных голоса по бокам (ширина, для соло — 0–10); Pitch < LFO (вибрато). Для удерживаемых звуков (орган, смычок, язычок): S Loop On = On, S Loop Fade заметный, Ve Sustain 1.0. Для щипков и ударных: Loop Off, Ve Sustain 0.

## Simpler: огибающие и фильтр
Ve Attack, Ve Decay, Ve Sustain, Ve Release (display в ms/s; Ve Sustain 0…1), Ve Mode (None, Loop, Beat, Sync, Trigger), Ve Retrig, Fade In / Fade Out (для One-Shot). Фильтр: F On; Filter Type (Lowpass, Highpass, Bandpass, Notch, Morph); Filter Circuit - LP/HP (Clean, OSR, MS2, SMP, PRD); Filter Slope (12 dB, 24 dB); Filter Freq (display «5 kHz»; по умолчанию открыт на максимум); Filter Res (0…1.25), Filter Drive (0…24 dB); Fe On, Fe < Env (глубина огибающей фильтра, ±72), Fe Attack/Decay/Sustain/Release; Filt < Key (слежение), Filt < Vel, Filt < LFO. Pe On, Pe < Env (±48 полутонов), Pe Attack/Decay/Sustain/Release — питч-огибающая (скольжение в ноту). Volume (−36…36 dB, по умолчанию −12), Vol < Vel (0.35 по умолчанию; для баяна/органа ставьте 0–0.1, для рояля 0.4–0.6), Vol < LFO (тремоло), Pan, Pan < Rnd, Pan < LFO.

## Simpler: типовые приёмы
Осветлить сэмпл: поднять Filter Freq, Filter Res малый, при необходимости выше Filter Drive 2–4 dB. Затемнить: Filter Freq в сторону 3–4 kHz. Укоротить хвост: Ve Release 80–200 ms, Ve Decay + Ve Sustain ниже. Сделать мягче атаку: Ve Attack 10–40 ms. Изменить тембр без изменения высоты — нельзя (Transpose меняет и тембр-формант); для «меньше Chipmunk» не уводите Transpose дальше ±5 полутонов от корневой высоты сэмпла. Для «пэд из сэмпла»: S Loop On, Loop Fade, Ve Attack 300–800 ms, Release 1–2 s, Spread 20–40, затем Reverb. Для стерео-ширины предпочитайте Spread или Chorus-Ensemble, но не оба сразу.
