# Клавишные, мэллеты, колокола: рояль, электропиано, орган, маримба, колокол — FM-отношения

## Клавишные: рояль
Рояль — молоточек бьёт по струнам: у каждой ноты 1–3 струны, чуть расстроенные (биения), гармоники растянуты (inharmonicity — верхние слегка выше целого кратного), распад двухстадийный (быстрый, затем медленный хвост; низкие ноты дольше), сильный удар → ярче. Корпус и дека добавляют сложные резонансы, педаль — симпатические струны. FM-приближение (Operator, Alg. 1, цепочка D→C→B→A): A Sine Coarse 1 (Ae Decay ≈ 7 s, Sustain 0); B Sine Coarse 1, Level −11 dB (мягкая «струнная» гармоничность, Be Decay 1.6 s — тембр темнеет по затуханию); C Coarse 4 и D Coarse 14, очень короткие (140 и 28 ms) — удар молоточка; Time < Key +40 %; Lev < Vel (для B/C) +50…+70 % — сильнее играешь, ярче; Filt < Key 30–50 %. EQ: High Pass 35 Hz, Bell −2 dB 280 Hz (картон), Bell +1.5 dB 3.2 kHz, High Shelf −3 dB 10 kHz; параллельная компрессия 45 %; комната 1.9 s, 14 %. Хорус не нужен. Реализм рояля синтезом ограничен — берите сэмпловый пресет.

## Клавишные: электропиано (Rhodes, Wurlitzer, DX)
Rhodes/DX-электропиано: FM с отношением 1:1. Operator Alg. 1: A Sine Coarse 1, Ae Decay ≈ 3.2 s, Sustain 0; B Sine Coarse 1, Level −13 dB, Be Decay ≈ 650 ms — «колокольчик» зубца в начале; C Sine Coarse 14, Level −26 dB, Ce Decay ≈ 40 ms — металлический «клик»; velocity усиливает B (Osc-B Lev < Vel +60 %) — «лай» при сильной игре. Wurlitzer: A Triangle Coarse 1, B Sine Coarse 2 (чётные гармоники, язычок), C Coarse 8 −26 dB 22 ms, затухание короче (1.4 s), Overdrive Drive 20 % / 45 % wet. Эффекты электропиано (здесь они к месту): Saturator Soft Sine 4 dB, Auto Pan с Phase 0° и Frequency 4.8 Hz Amount 18 % — тремоло «чемодана», Chorus-Ensemble Dry/Wet 25–30 %, комната 1.6 s. Тембр темнее: убавить Osc-B Level на 2–3 dB, Filter Freq ниже; ярче — поднять B Level и C Level, Be Decay длиннее.

## Клавишные: орган
Орган Hammond (тоновые колёса) — аддитивный: девять драйбаров 16', 5⅓', 8', 4', 2⅔', 2', 1⅗', 1⅓', 1' соответствуют синусам на отношениях 0.5, 1.5, 1, 2, 3, 4, 5, 6, 8 к основной частоте. Operator Alg. 11 даёт 4 синуса: A Coarse 1 (8'), B Coarse 2 (4'), C Coarse 3 (2⅔'), D Coarse 4 (2'), Sustain 1.0, Attack 3–5 ms (мгновенный орган), Release 20–40 ms, лёгкий клик (Noise White −40 dB, 8 ms). 16' и 5⅓' требуют отдельного экземпляра. Перкуссия: 2-я или 3-я гармоника с Decay 200–300 ms, Sustain 0. Leslie: Chorus-Ensemble Mode Vibrato или Phaser + Auto Pan (Phase 0, Frequency 6.5 Hz, Amount 15 %). Церковный (пайповый) орган: Attack 70–95 ms (нижние трубы говорят дольше, верхние гармоники позже), Release 400 ms, ряды 8'/4'/2⅔' синусами + треугольник 16', реверб 6 s, 38 %, Predelay 28 ms, срез от 6 kHz. Хорус — небольшой (Ensemble 20 %) только как «селеста».

## Мэллеты: маримба, вибрафон, ксилофон, глокеншпиль
Деревянные бруски маримбы настроены на частоты 1 : 4 : 10 (основной тон, две октавы + 10-я гармоника) — получается звонкая, но чистая нота. Operator Alg. 11: A Sine Coarse 1 (Ae Decay 650 ms, Sustain 0), B Sine Coarse 4 (120 ms), C Sine Coarse 10 (40 ms), D Noise White (12 ms, −30 dB — удар колотушки), Time < Key 40 %, Filter Lowpass 5 kHz. Вибрафон: металл, A Sine Decay 2.5–4 s, B Sine Coarse 4 −18 dB (короткий), длинный Release и Auto Pan Phase 0 при 5 Hz (мотор-вибрато). Ксилофон — короче и ярче (Decay 250 ms, Saw 8 + Sine). Глокеншпиль/металлические пластины — негармонично: отношения ≈ 1 : 2.76 : 5.40 : 8.93; с учётом записи рецептов проекта: A Coarse 1, B Coarse 2 Fine 760, C Coarse 5 Fine 400, D Coarse 8 Fine 930 (отношение трактуется как Coarse + Fine/1000), верхние парциалы затухают быстрее (250 мс против 2.5 с), Time < Key 35 %. Стил-пэн: 1 : 2 : 3 + короткий ×4, Fine 5–6 для биения, Decay 1.6 s. Музыкальная шкатулка: Sine + пинг ×6 с Decay 60 ms, Time < Key 40 %.

## Колокола: FM и негармоничные отношения
Колокол — трёхмерный резонатор: удар даёт быстро угасающие негармоничные парциалы; затем «strike note» — несколько сильных гармоник в отношении примерно 2 : 3 : 4 (слух домысливает основу); затем «hum» — тихий звук на октаву ниже, с биением близких мод. FM: нецелое отношение несущая/модулятор даёт негармонический спектр; чем больше индекс (Level модулятора), тем «ломче». Операторный рецепт трубчатых колоколов (Alg. 1, C→B→A): A Sine Coarse 1 (Ae Decay 5 s, Sustain 0, Release 1.2 s); B Sine Coarse 3 Fine 500 (отношение ≈ 3.5), Level −8 dB, Be Decay вдвое короче A; C Sine Coarse 1 Fine 410 (отношение ≈ 1.41), Level −18 dB; Time < Key 20–30 %; EQ Bell −1.5 dB 700 Hz; Reverb Decay 4.5 s, Dry/Wet 34 %. Для «церковного» колокола добавьте слой октавой ниже (hum) с медленным биением (2 близких синуса Fine 2–4) и длинным хвостом. Для «глуше» — ниже Level модулятора и короче его Decay; для «звонче» — выше Level B и C.
