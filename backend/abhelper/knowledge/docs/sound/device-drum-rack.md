# Drum Rack: основы

## Drum Rack: устройство
Drum Rack — контейнер на 128 ячеек (pad): каждая ячейка соответствует одной MIDI-ноте и содержит цепочку (chain) с инструментом (чаще Simpler с сэмплом) и аудио-эффектами. Видимые 16 пэдов листаются группами; в нумерации Live (C3 = 60) стандартный набор начинается с ноты 36 (C1): 36 — кик, 38 — снейр, 39 — клэп, 42 — закрытый хэт, 46 — открытый, 49 — крэш (раскладка General MIDI). У Drum Rack по API есть только Macro 1…16 (0…127); пэды и цепочки параметрами устройства не видны. Поэтому кит почти всегда берут из браузера Live (пресеты ударных, например «808 Core Kit», «909 Core Kit», акустические киты), а затем правят отдельные цепочки.

## Drum Rack: цепочки, choke, send
У каждой цепочки: Receive (на какую ноту отвечает), Play (какую ноту отдаёт внутрь — меняет высоту сэмпла), Choke (группа 1…16: срабатывание одной цепочки глушит другие в группе — закрытый хэт обрывает открытый), Mute/Solo, Hot-Swap, регуляторы Volume/Pan. Отправки (Sends) идут в Return-цепочки внутри рэка — до шести. Нет зон по velocity/клавишам (в отличие от Instrument Rack). Для слоёв (кик + саб) кладут несколько сэмплов в один пэд через вложенный Instrument Rack. Сэмпл в пэде — Simpler: его Transpose, Ve Decay (укоротить/удлинить), Filter Freq (потемнее/поярче), Volume (−12 dB по умолчанию). В готовом ките самые частые правки: укоротить кик (Ve Decay 150 ms), поднять питч снейра (+1…+3 st), сгладить хэт (Filter Freq 9 kHz).

## Drum Rack: обработка кита
Общий звук склеивают на уровне всего рэка: Drum Buss (Drive, Crunch, Boom, Transients) — «плотность» и низ; Glue Compressor (ratio 4, атака 10 ms, релиз 0.2 s, сжатие 2–4 dB) — склейка; EQ Eight: срез ниже 30 Hz, чистка 250–400 Hz; Saturator (Drive 3–6 dB) для тепла. Параллельная компрессия — Return с Compressor (Ratio 8, Attack 1 ms, Release 80 ms), Send на 20–30 %. Хэты и перкуссию стоит уводить в сторону Pan 10–30 %, кик и снейр — центр. Учтите стиль: 808 — длинный синус-кик (Decay 0.5–2 s), живой кит — короткие сухие удары и небольшая комната (Reverb Decay 0.6–1 s).
