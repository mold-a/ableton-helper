# Прилагательные → параметры: что крутить («ярче», «теплее», «жирнее»…)
keywords: ярче, темнее, теплее, холоднее, жирнее, тоньше, мягче, резче, агрессивнее, грязнее, чище, винтажнее, воздушнее, ближе, дальше, шире, уже, сочнее, панчевее, живее, натуральнее, меньше синтетики, brighter, darker, warmer, colder, fatter, thinner, softer, harsher, dirtier, cleaner, vintage, airy, wider, narrower, punchier, tweak, подкрутить, улучшить звук, сделай, как изменить звук, adjective, user request, cutoff, attack, release

## Как применять эти правила
Правка по просьбе пользователя: сначала прочитайте текущие значения (get_device_parameters), затем меняйте 1–3 параметра за шаг и слушайте. Шаги во всей таблице — в единицах отображения Live: срез ×1.5–2 (≈ +0.6…+1 октава), время атаки ×3–6 (5→30 ms), Dry/Wet реверба ±8–10 %, EQ ±1.5–3 dB. Не крутите всё сразу: тогда непонятно, что помогло. Название нужных параметров по устройствам: срез — Operator `Filter Freq`, Analog `F1 Freq`, Drift `LP Freq`, Wavetable `Filter 1 Freq`, Simpler `Filter Freq`; резонанс — `Filter Res` / `F1 Resonance` / `LP Reso` / `Filter 1 Res`; атака громкости — `Ae Attack` (+ Be/Ce/De), `AEG1 Attack`, `Env 1 Attack`, `Amp Attack`, `Ve Attack`; релиз — `Ae Release`, `AEG1 Rel`, `Env 1 Release`, `Amp Release`, `Ve Release`; глубина огибающей фильтра — Operator `Fe Amount`, Analog `F1 Freq < Env`, Simpler `Fe < Env`; расстройка — `B Fine`, `OSC2 Detune`, `Osc 2 Detune`, Simpler `Detune`; ширина — `Spread`, `Unison Detune`, `Unison Amount`. Для «чуть-чуть» берите нижнюю границу указанного шага, для «намного» — верхнюю (и повторяйте шаг, если мало). Всегда оставляйте запас по уровню.

## Ярче (светлее, звонче, больше верха)
Ярче в синтезаторе: поднять срез фильтра ×1.5–2 (напр. Filter Freq 2.4 kHz → 4 kHz), при необходимости Fe Amount +5…+10 (огибающая фильтра раскрывает сильнее) или Filt < Vel +20 %; добавить гармоник — заменить Saw 16 → Saw 32/64 (Operator), поднять октавный осциллятор (4′) на +3 dB, Tone +0.1…+0.15, Shaper Soft +3 dB (Mix 30 %); EQ Eight: High Shelf +2 dB от 8–10 kHz или Bell +2 dB на 3 kHz (Q 1); Reverb: HiFilter Freq 6 → 9 kHz. Saturator Drive +2…+3 dB добавляет «верх» гармониками. Не делайте: резонанс выше 0.4 (звон), подъём 2–4 kHz более +4 dB на постоянных тонах (режет уши), яркость выше 10 kHz на пиле без срезания (песок). Если звук одновременно «жёсткий» — яркость нужна только после огибающей: поднимайте Fe Amount, а не постоянный срез.

## Темнее (глуше, мягче верх)
Срез ÷1.5–2 (Filter Freq 5 kHz → 3 kHz), Tone −0.15 (Operator), Saw 64 → Saw 16 или Square/Triangle вместо Saw, уровень верхнего осциллятора (4′) −4 dB; Fe Amount −5…−10; Filt < Vel меньше. EQ: High Shelf −2…−3 dB от 6–8 kHz; Reverb: HiFilter Freq 4–5 kHz, HiFilter Type: Lowpass. Аналоговый способ: Low-pass 24dB/oct вместо 12dB (резче срез). Не делайте: не срезайте ниже 1.5 kHz для сольного инструмента (теряется артикуляция — звук «за шторой»); тройное затемнение (фильтр + полка + реверб HiFilter) сделает тембр ватным. Если нужно «темнее, но чётко» — срезайте ярко-шипящую полосу 5–8 kHz и сохраните присутствие 2–3 kHz.

## Теплее (мягче, ламповее) и холоднее
Теплее: Low Shelf +1.5…+2 dB от 150–250 Hz; Bell −1.5 dB на 3.5 kHz (убирает «холодную» резкость); High Shelf −1.5 dB от 9 kHz; Saturator Type Soft Sine или Analog Clip, Drive 3–5 dB, Output −2 dB; срез ÷1.3; добавить Triangle/Sine в смесь; Drift: Drift 0.1–0.15, LP Type I (12 dB); Analog: F1 Drive Sym1. Холоднее/прозрачнее/«стекло»: срез ×1.3, Bell −2 dB на 250–350 Hz (убрать муть), High Shelf +2 dB от 10 kHz, меньше сатурации (−3 dB Drive), Square/Sine вместо Saw. Не делайте: тёплое ≠ тёмное — не срезайте всё сверху; не добавляйте хорус на соло-акустике ради «тепла».

## Жирнее (толще, плотнее) и тоньше
Жирнее: второй осциллятор с лёгкой расстройкой (Operator `B Fine` 2–6 ≈ 3–10 cents; Analog `OSC2 Detune` ≈ +5…+10 ct; Drift `Osc 2 Detune` на ±0.02–0.05); слой октавой ниже (Coarse 0 / Octave −1) на −8…−10 dB; для пэдов и лидов — Unison 2–4 голоса, Spread 20–40 %; Saturator Drive 4–6 dB; EQ Low Shelf +2 dB от 120 Hz; Chorus-Ensemble Dry/Wet 20–30 % (пэды, электропиано). Тоньше/легче: убрать суб-слой (−6…−10 dB), High Pass 12dB 150–250 Hz, уменьшить Unison и Spread, срез ×1.2. Не делайте: Unison/Spread/Chorus на соло-акустических инструментах и на басе ниже 150 Hz (моно!); +6 dB на 100–200 Hz без компенсации Output Gain — получите муть и перегруз мастера.

## Мягче атака / резче атака
Мягче: Ae Attack (AEG1 Attack, Env 1 Attack, Amp Attack, Ve Attack) с 5 до 30 ms (×3–6), у фильтра Fe Attack 30–60 ms; убрать шумовой щелчок (уровень −6 dB); Filt < Vel / Lev < Vel меньше; Compressor Attack короче (3–5 ms) прижимает удар. Резче: атака 30 → 3 ms; добавить щелчок — Noise White −32…−28 dB с Decay 8 ms; Fe Amount +5, Fe Decay 100–200 ms; Drum Buss Transients +0.2…+0.3; Compressor Attack 20–30 ms (удар проходит), EQ Bell +2 dB 3–5 kHz. Пример: баян — атака 28 → 10 ms делает «клапан» резче; органу нужна атака 3–5 ms, смычку 80–120 ms, пэду 300+ ms. Не делайте: атака 0 ms на низких нотах без Time < Key — щелчок; атака более 100 ms на ритмичных партиях — «опаздывает».

## Короче хвост / длиннее хвост (спад, релиз)
Короче: у щипков и мэллетов — Ae Decay ×0.5 (1.4 s → 0.7 s) и Time < Key +10…+20 %; у удерживаемых тонов — Ae Release 400 → 120 ms; Reverb Decay Time ×0.6–0.7 (2 s → 1.3 s); Delay Feedback −10 %. Длиннее: Decay ×1.5–2, Release 120 → 400 ms, Reverb Decay +0.5 s, Delay Feedback +10 % (до 45 %). Для щипка сустейн остаётся 0 (длину ноты задаёт Decay); чтобы нота «держалась», подключайте Sustain > 0 только для удерживаемых инструментов. Не делайте: бесконечный Release на плотных партиях (хвосты налезают друг на друга); Reverb Decay > 2 s на быстрой музыке — каша.

## Больше / меньше реверба, ближе / дальше
Больше: Reverb Dry/Wet +8–10 % (на insert) или Send выше; Decay Time +0.3…+0.5 s. Меньше: Dry/Wet −8 %, Decay ×0.7. Ближе (передний план, интимнее): Dry/Wet −8 %, Decay ×0.7, Predelay 10 → 25 ms (сухой удар отделён от хвоста), HiFilter Freq вниз 1–2 kHz, High Shelf −2 dB, чуть больше верха сухого сигнала. Дальше (глубже, на заднем плане): Dry/Wet +10 %, Predelay 5 ms, Decay ×1.3, срез верха 1.5 kHz ниже, Stereo Image шире. Разумные пределы: соло-инструмент 10–18 %, пэд 20–35 %, ударные 5–12 %. Не делайте: реверб на басу и кике; Chorus On в Reverb для акустических тембров; длинный хвост с Freeze.

## Шире / уже
Шире: Spread 15–25 % (Operator, Simpler, Drift Spread), Unison 2–4 голоса (пэды), Utility Stereo Width 100 → 130–150 %, Chorus-Ensemble Width 150 %, Reverb Stereo Image выше, Delay с разными L Time/R Time (12/17 ms, Dry/Wet 12–15 %). Уже/центрированнее: Utility Stereo Width 70–90 % или Mono, Spread 0, Unison Off, Bass Mono On (Bass Freq 120–150 Hz). Проверка совместимости: включите Utility Mono — если звук падает >4 dB или пропадают частоты, уменьшите расширение. Не делайте: ширину на сабах и соло-вокале-подобных инструментах (баян, труба), Width > 160 % (фазовая каша) и Spread в сочетании с Chorus на одной дорожке.

## Агрессивнее / мягче
Агрессивнее: Saturator Hard Curve или Sinoid Fold, Drive 8–14 dB; Overdrive Drive +15–25 %; резонанс фильтра +0.1…+0.2; Fe Amount ↑ и Fe Decay короче; атака короче; EQ Bell +2 dB 2–4 kHz; Compressor Ratio 4:1, GR 4–6 dB; Filt < Vel +20 %. Мягче: Saturator Soft Sine Drive 2 dB; срез ÷1.5; резонанс до 0.1; атака длиннее (×2–3); High Shelf −2…−3 dB; Compressor Attack короче/Ratio 2:1; Lev < Vel меньше. Не делайте: резонанс >0.7 вместе с Drive (самоосцилляция и пики); подъём 3 kHz >+4 dB; жёсткий клиппинг на мастере — следите за запасом −6 dBFS.

## Грязнее / чище, винтажнее / современнее
Грязнее: Redux Bit Depth 12–14, Sample Rate 12 kHz, Dry/Wet 30–50 %; Overdrive Drive 20–30 %; шум Noise −36 dB; Vinyl Distortion Crackle Volume 0.1–0.2. Чище: убрать эти эффекты, Saturator Drive −3…−6 dB, Noise выкл., Spread/Chorus меньше. Винтажнее: Drift 0.15–0.25 (случайное «плавание»), Analog Key Error/Vib Error выше, срез 4–5 kHz, High Shelf −3 dB от 8 kHz, Saturator Soft Sine 3–5 dB (лента), для пэдов/электропиано Chorus Classic 20–30 %, Reverb пластина 1.5 s, Delay Mode Repitch с Mod Freq. Современнее: яркость выше, широкий стерео, Saturator Digital Clip осторожно, меньше шума. Не делайте: Redux на басе (песок), Vinyl crackle на всём миксе, Chorus на соло-акустике ради «винтажности».

## Воздушнее / сочнее / панчевее
Воздушнее: High Shelf +2…+3 dB от 10–12 kHz, шум дыхания Noise −34 dB, Reverb Predelay 15–25 ms + In LowCut On ≈ 200 Hz, HiFilter Freq 8–10 kHz; без хоруса. Сочнее (насыщеннее, «вкуснее»): Saturator Soft Sine Drive 2–4 dB, Bell +1.5 dB 800 Hz–1.2 kHz, мягкая компрессия GR 2 dB, лёгкий слой октавой ниже −10 dB. Панчевее: атака 1–5 ms, Decay короче, Pitch Envelope +6…+12 st (для ударных), Compressor Attack 20–30 ms, Release 80–120 ms, Ratio 4:1, GR 3–5 dB, Drum Buss Transients +0.3, EQ +2 dB на 80–100 Hz и 3–5 kHz, Reverb короче/меньше. Не делайте: сочность через 300 Hz (получится муть); панч без запаса уровня (клиппинг); воздух >+4 dB (шипение).

## Живее / натуральнее / меньше «синтетики»
Живее (не статично): Retrig Off у осцилляторов (Operator `Osc-B Retrig`), малая расстройка осцилляторов 2–5 ct, Drift 0.08–0.15, Analog Key Error и Vib Error ↑, очень медленный LFO на срез (±3–5 %), разброс velocity ±8–12, ноты аккорда со сдвигом 15–40 ms, лёгкая `Pan < Rnd` (Operator `Pan < Rnd` 5–10). Меньше синтетики: убрать статичные хорус/унисон на соло-инструментах; добавить шум дыхания/щелчок атаки (Noise −38…−32 dB, 8–25 ms); связать яркость с velocity/громкостью (Filt < Vel 20–40 %); `Time < Key` и `Filt < Key`; корпусной EQ (форманта инструмента) и небольшая комната вместо зала; снизить «идеальность» (Operator Tone −0.1, Saw 64 → 32); слой реального сэмпла под синтезом. Не делайте: вибрато с первой миллисекунды, 100 % Unison, одинаковую velocity у всех нот (кроме баяна/органа), мягкий «пэд-реверб» на всём.

## Муть, резкость, нос, присутствие
Муть/«картон»: EQ Bell −2…−3 dB на 250–350 Hz (Q 1), High Pass 12dB 70–120 Hz, In LowCut в ревербе 200 Hz. Резкость/«звон»: Bell −2…−3 dB на 2.5–4 kHz (Q 1.5), срез ÷1.3, резонанс ↓, Saturator Soft Sine вместо Hard. Нос/«носовой»: Bell +3…+4 dB на 0.9–1.3 kHz Q 2 (язычковые, гобой, сакс) или Bandpass фильтр; убрать нос: Bell −3 dB на 1 kHz. Присутствие/«в лицо»: Bell +2…+3 dB на 2–4 kHz, Filt < Vel +20 %, Compressor с Attack 20 ms. Больше баса: Low Shelf +2 dB от 100 Hz, слой Coarse 0 (−10 dB), Sub-осциллятор; меньше баса: High Pass 120–150 Hz. Не делайте: узкие подъёмы (Q>4) на длинных нотах; подъём 1 kHz на баяне/гармонике более +4 dB.

## Громче / тише, динамичнее
Громче: поднять Volume инструмента на 2–3 dB или Utility Gain +3 dB; для кажущейся громкости — Saturator Drive +2 dB (Output −1 dB), лёгкое сжатие GR 2–3 dB, яркость 2–4 kHz +1.5 dB. Тише: Utility Gain −3 dB. Динамичнее (разница тихого и громкого): Vol < Vel / Osc Lev < Vel 0.4–0.6, Filt < Vel 30 %, Compressor Ratio ниже/Attack дольше. Менее динамично (ровнее): velocity-зависимость 0, Compressor 3:1 GR 3 dB. Правило запаса: пики канала не выше −6 dBFS, Volume инструмента −6 dB — стартовое значение; ступень «заметно громче» — 3 dB, «чуть-чуть» — 1 dB. Не делайте: компенсировать плохой баланс только громкостью, поднимать Volume выше 0 dB, смешивать «до/после» без выравнивания громкости (громче всегда кажется лучше).

## Выше / ниже, вибрато, плавность
Выше/ниже по высоте: Transpose ±12 (октава) или Coarse (Operator: 0 → ×0.5 вниз, 2 → вверх), Osc Octave (Analog/Drift); «чуть-чуть» — Detune ±10 ct. Больше вибрато: Analog `Vib Amount` +0.1 (norm) и `Vib Delay` 300–500 ms, скорость 5–6 Hz; Operator — LFO Amt A выше (цель — pitch), Le Attack 300–500 ms; меньше вибрато — Amount ÷2, задержка дольше; для баяна, органа, клавишных — вибрато 0. Плавнее/легато: Glide On (Glide Time 30–60 ms), Glide Legato On (Analog), Mono voices; Release 100–200 ms. Резче/дробнее: Glide Off, Release 40–80 ms. Не делайте: вибрато 8 Hz+ (звучит как сирена), глайд >150 ms на мелодиях.
