# Delay: эффект задержки (Live 11.3.25)
keywords: delay, дилей, задержка, эхо, echo, ping pong, пинг-понг, feedback, фидбэк, slapback, слэпбэк, sync, 16th, dotted, tape delay, dry/wet, повторы

## Delay: параметры
Delay — две независимые линии (левая L, правая R). L Sync / R Sync = On: время в долях темпа — L 16th / R 16th задают число 16-х (значения 1, 2, 3, 4, 5, 6, 8, 16): 2 = восьмая, 3 = восьмая с точкой, 4 = четверть, 8 = половинная; при Sync = Off время задают L Time / R Time в миллисекундах (display «350 ms»). Link = On копирует левую линию в правую. L Offset / R Offset — небольшой сдвиг времени (для «разболтанности»). Feedback (display в %): доля, возвращаемая в линию. Ping Pong = On — повторы прыгают между каналами. Filter On, Filter Freq, Filter Width — полосовой фильтр в петле (повторы темнеют/светлеют). Mod Freq, Dly < Mod (модуляция времени — «лента»), Filter < Mod. Delay Mode при смене времени: Repitch (плавающая высота, как лента), Fade, Jump (щелчки). Freeze бесконечно зацикливает буфер. Dry/Wet — баланс.

## Delay: готовые настройки
Слэпбэк (гитара, вокал, «плотность»): Sync = Off, L Time/R Time 80–120 ms, Feedback 0–15 %, Dry/Wet 10–20 %. Эхо восьмыми: Sync = On, L 16th 2 (в обоих), Feedback 25–40 %, Filter On, Filter Freq ≈ 1–3 kHz (Width ≈ 4–6), Dry/Wet 12–20 %. Пинг-понг в тактах: Ping Pong On, L 16th 3 / R 16th 4 для «шагающего» эха, Feedback 30–45 %. Тёмное дабовое эхо: Filter Freq 700–1.2 kHz, Feedback 45–55 %, Dry/Wet 20–30 %. «Лента»: Mod Freq слабая, Dly < Mod небольшая, Delay Mode Repitch. Для соло-акустики (баян, флейта) задержку держите коротко и тихо (Dry/Wet ≤ 12 %), иначе пропадает ощущение живого исполнения. На return-треке — Dry/Wet 100 %.

## Delay: чего избегать
Feedback выше 60 % без Filter приводит к накоплению мути и росту уровня — повторы «захлёбываются»; не выше 55 % для постоянных сигналов. Повторы на низких нотах басовой партии размывают бит — подрезайте HP в фильтре задержки (Filter Freq > 200 Hz) или ставьте Delay на return с EQ. Синхронные повторы на 1/4 и 1/8 поверх реверба должны идти до ревербератора (Delay → Reverb), а не наоборот. Не используйте режим Repitch при автоматизации времени, если не хотите «слайда» высоты. Если задержка нужна для «ширины» (а не как эхо), используйте разные короткие L Time/R Time (например 12 и 17 ms) и Dry/Wet ≈ 15 % — но проверьте моно-совместимость.
