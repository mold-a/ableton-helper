# Operator: гид по синтезатору (Live 11.3.25)
keywords: operator, оператор, fm, фм синтез, частотная модуляция, алгоритм, algorithm, coarse, fine, carrier, modulator, несущая, модулятор, osc-a, osc-b, ae attack, filter freq, fe amount, pitch envelope, питч-огибающая, shaper, spread, tone, time, аддитивный, ratio, отношение частот, алгоритм 11, alg 11

## Operator: сигнальный путь
Operator — четыре осциллятора A, B, C, D, у каждого своя огибающая (Ae, Be, Ce, De) и уровень (Osc-A Level …). Осцилляторы соединены выбранным Algorithm: каждый либо идёт на выход (несущая, carrier), либо модулирует по частоте другой (модулятор). Дальше сумма идёт в Filter (огибающая Fe, LFO), затем в Shaper, потом Spread (стерео-удвоение), Tone, Volume. Отдельно есть Pitch Envelope (Pe), LFO (с огибающей Le) и Glide. Для аддитивной/вычитающей работы (язычковые, органы, струнные, щипки) берут Alg. 11: все четыре осциллятора параллельно, каждый — слышимый «голос» со своей огибающей. Для FM (колокола, электропианино, FM-басы) берут алгоритмы с цепочками. Важно: значения «по умолчанию» не нейтральны — Osc-B/C/D Level = 0 (молчат), Filter On = On с частотой в середине диапазона, Ae Sustain = 1. Всегда явно задавайте Filter Freq и уровни неиспользуемых осцилляторов (лучше Osc-X On = Off).

## Operator: алгоритмы (Alg. 1 … Alg. 11)
Значения параметра Algorithm: «Alg. 1» … «Alg. 11». Проверено по документации и обзорам: Alg. 1 — цепочка D→C→B→A, слышен только A (максимально глубокая FM). Alg. 2 — C и D вместе модулируют B, B модулирует A (A единственная несущая). Alg. 8 — две пары: B→A и D→C, несущие A и C (удобно для электропиано/колоколов: два независимых FM-слоя). Alg. 11 — все четыре осциллятора параллельно, FM нет, это 4-голосный аддитивный синтезатор. Точные схемы Alg. 3–7, 9, 10 в доступных источниках не подтверждены; ориентир — чем больше номер, тем больше несущих, но не полагайтесь на это без проверки. Правило: уровень (Osc-X Level) у модулятора — это глубина модуляции (индекс), а не громкость; у несущей — громкость. Feedback (Osc-X Feedb) доступен только осциллятору, который сам не модулируется другим. Смена алгоритма может превратить тихий модулятор в громкую несущую — после смены проверяйте баланс.

## Operator: высота — Coarse, Fine, Transpose, Fixed
A Coarse / B Coarse … — множитель частоты относительно сыгранной ноты, а не полутона: Coarse 0 = ×0.5 (октава вниз), 1 = ×1 (унисон), 2 = октава вверх, 3 = октава+квинта, 4 = две октавы, 5 = ×5 (две октавы + большая терция) и т. д. (диапазон 0…48, целые числа = гармонический ряд).
Fine (0…1000) добавляет сдвиг внутри октавы: шкала 1000 шагов ≈ одна октава, у нуля один шаг порядка 1.2–1.7 цента (источники расходятся в интерпретации: доля октавы или добавка к отношению частот), поэтому для «живого» биения двух осцилляторов ставьте Fine 2–10 (≈3–15 центов), для сильного детюна 15–25.
Fine только добавляет к Coarse (вверх), поэтому «вниз от унисона» обычным способом не расстроить: используйте Spread или другой синтезатор (Analog/Drift) с двусторонним Detune.
Для нецелых отношений (колокола, пластины) берут Coarse + Fine: например 2.76 = Coarse 2, Fine 760 (так записаны рецепты проекта; если колокол звучит гармонично, отношение трактуется иначе — проверяйте на слух).
A Quantize = On округляет сдвиг Freq<Vel до целых.
Transpose (−48…48 st) сдвигает весь инструмент в полутонах.
Fixed (A Fix On) отвязывает частоту от ноты: A Fix Freq и A Fix Freq Mul задают её (до 0.1 Гц) — для шумовых ударов и модуляторов в перкуссии.
Если модулятор Fixed, отношение несущая/модулятор меняется от ноты к ноте.

## Operator: формы волны (Osc-A Wave)
Список значений: Sine, Sine 4 Bit, Sine 8 Bit, Saw 3, Saw 4, Saw 6, Saw 8, Saw 16, Saw 32, Saw 64, Saw D, Square 3, Square 4, Square 6, Square 8, Square 16, Square 32, Square 64, Square D, Triangle, Noise Looped, Noise White, User. Число в названии — сколько гармоник содержит ресинтезированная волна: Saw 3 мягкая и тёмная, Saw 64 почти идеальная яркая пила. Из-за этого верхняя граница спектра привязана к высоте ноты (16·f): на низких нотах Saw 16 даёт тусклый звук, на высоких — достаточно ярко. Для живых язычковых и струнных берите Saw 32/64 и режьте яркость фильтром. Square — только нечётные гармоники («пустой», кларнет/орган), Triangle — мягкая флейта/гул, Sine — чистая несущая, саб, чистые гармоники для аддитивного синтеза. Sine 4/8 Bit — «чиптюн», Saw D/Square D — цифровые басовые. Noise White — щелчки, дыхание, ударные. User — своя гармоническая картинка (по API задать нельзя).

## Operator: уровни, фаза, чувствительность
Osc-A Level показывается в dB (0 dB — максимум). Осцилляторы с уровнем меньше −40 dB практически не слышны, шаг «заметно тише» — 3–6 dB. Osc-A Retrig = On заставляет волну стартовать с одной и той же фазы на каждой ноте (звук одинаково «щёлкает»); Off — осциллятор свободно бежит, фазы разных осцилляторов постоянно скользят друг относительно друга, что убирает статичную «гребёнку» и делает биение естественным (полезно для язычковых и хоров). Osc-A Phase (0…100 %) задаёт фазу при Retrig. Osc-A Lev < Vel (−100…100 %) — зависимость громкости (или глубины модуляции) от силы нажатия; для модулятора это «лай при сильной игре». Osc-A Lev < Key — от высоты ноты. A Freq<Vel меняет частоту от velocity (для перкуссии). Для инструментов без динамики по касанию (баян, орган) оставляйте Lev < Vel = 0.

## Operator: огибающие Ae/Be/Ce/De
У каждого осциллятора: Ae Init (начальный уровень), Ae Attack (время), Ae Peak (пик), Ae Decay (до Sustain), Ae Sustain, Ae Release. Времена показываются в ms/s: 1 ms — мгновенная атака, 5–15 ms — быстрая, но без щелчка, 30–80 ms — мягкая, 300+ ms — смычки/пэды. Уровни Init/Peak/Sustain — числа 0…1 (в интерфейсе в dB: 1.0 = 0 dB, 0.0 = тишина). Для затухающих звуков (щипок, колокол) Ae Sustain = 0.0 и длина ноты задаётся Ae Decay; для удерживаемых (орган, язычок, смычок) Ae Sustain = 1.0. Time (−100…100) масштабирует времена всех огибающих сразу; Time < Key (−100…100 %) — чем выше нота, тем быстрее огибающие (25–40 % для струн/мэллетов); Ae R < Vel — зависимость релиза от velocity. Ae Mode: None (обычная), Loop/Beat/Sync (повтор — для ритмичных текстур), Trigger (игнорировать Note Off — для ударных). Для модулятора огибающая управляет тембром: короткая Be Decay = яркая атака, потом чистый тон.

## Operator: фильтр и его огибающая
Filter On / Filter Type: Lowpass, Highpass, Bandpass, Notch, Morph. Filter Circuit - LP/HP: Clean, OSR, MS2, SMP, PRD (Clean — как EQ Eight, без Drive; остальные имитируют аналоговые схемы, у них работает Filter Drive 0…24 dB и резонанс «поёт»). Filter Slope: 12 dB или 24 dB (24 dB срезает жёстче). Filter Freq — частота среза в Hz/kHz (диапазон ≈20 Hz…20 kHz): 800 Hz — тёмный, 2–3 kHz — нейтральный, 6–8 kHz — яркий. Filter Res 0…1.25: до 0.2 — почти без пика, 0.3–0.5 — выраженный «нос», выше 1.0 (не Clean) — самоосцилляция. Filt < Key (−200…200 %): 100 % — срез идёт за нотой 1:1; 0–30 % — срез почти фиксирован (форманта), 40–80 % — для щипков и струнных. Filt < Vel — velocity открывает фильтр. Fe Amount (−100…100) — глубина огибающей фильтра; около 25 даёт примерно +2.5 октавы (оценка по рецептам проекта, проверяйте на слух). Fe Attack/Decay/Sustain/Release — как у амплитудной; для «открытия» тона Fe Sustain 0.2–0.6.

## Operator: LFO, питч-огибающая, Shaper, Spread, Tone
LFO On; LFO Type (Sine, Square, Triangle, SwUp, SwDown, S&H, Noise); LFO Range (Low, High, Sync) и LFO Rate (0…127, не в Hz); LFO Amt — общая глубина; цели: «Osc-A < LFO», «Filt < LFO» (On/Off) с глубиной LFO Amt A и дополнительная цель LFO Dst B (Filter Freq, Volume, Panorama, OSC Volume …) с LFO Amt B. Вибрато: Sine, Range Low, медленная скорость (≈5–6 Hz), цель — высота осцилляторов, малая глубина, а появление вибрато задержите огибающей LFO (Le Attack 300–500 ms). Pitch Envelope: Pe On, Pe Init/Peak/Sustain/End в полутонах (±48), Pe Decay — быстрый наклон высоты (808-кик +12 st за 70 ms), цель выбирается Osc-X < Pe. Shaper Type (Off, Soft, Hard, Sine, 4Bit), Shaper Mix, Shaper Drive (−12…12 dB) — мягкая насыщенность. Spread (0…100 %) удваивает голос с детюном и панорамой — ширина, но для сольных акустических инструментов используйте 0–10. Tone (по умолчанию 0.7) — яркость верха осцилляторов и антиалиасинг: ниже — темнее. Glide On/Glide Time, Volume (dB) — выход, оставляйте запас: −6 dB.
