# Analog: гид по синтезатору (Live 11.3.25)
keywords: analog, аналог, аналоговый синтезатор, вычитающий синтез, subtractive, osc1, osc2, f1 freq, f2, aeg1, feg1, unison, vibrato, вибрато, two channels, formant filter, noise, шум, sync, sub, key stretch, пила, прямоугольник, rect, pw, pulse width

## Analog: сигнальный путь
Analog — вычитающий синтезатор с двумя независимыми каналами. Канал 1: OSC1 → фильтр F1 → усилитель AMP1; канал 2: OSC2 → F2 → AMP2. Каждый канал имеет свои огибающие (FEG1/AEG1 и FEG2/AEG2) и свой LFO (LFO1/LFO2). Между осцилляторами и фильтрами работает Balance (OSC1 Balance, OSC2 Balance — распределение между F1 и F2; точное поведение при выключенном F2 проверяйте на слух), также есть Noise (Noise On/Off, Level, Color, Balance). F1 To F2 направляет выход F1 во второй фильтр (последовательное соединение), F2 Slave заставляет F2 следовать за F1. В свежем патче F2 и AMP2 выключены (F2 On/Off = Off, AMP2 On/Off = Off). Ловушка: если включить OSC2, но оставить AMP2 выключенным, а Balance направляет его в канал 2, осциллятор может звучать тише или не звучать — для простого однофильтрового патча используйте OSC1+OSC2 → F1/AMP1 и проверяйте, что оба слышны, либо включайте весь второй канал. Параметры 0…1 — нормированные; используйте display-значения (напр. «1.2 kHz», «28 ms»).

## Analog: осцилляторы
OSC1 Shape и OSC2 Shape: Sine, Saw, Rect, Noise. OSC1 PW (0…1, 0.5 = квадрат; меньше — уже, «носовее») работает только для Rect, O1 PW < LFO — модуляция ширины (хор/строки). OSC1 Octave (−3…3), OSC1 Semi (−12…12), OSC1 Detune (0…1, 0.5 = ноль, в центах, до ±300 ct — для биения хватает ±3…±12 ct). OSC1 Mode: Sub (суб-осциллятор на октаву ниже, O1 Sub/Sync = уровень; не работает с Noise) или Sync (O1 Sub/Sync = отношение синхронизации — классический «жужжащий» лид; при 0 эффекта нет). O1 Keytrack (0.5 = норма, 1:1). OSC1 Level — громкость осциллятора; PEG1 Amount и PEG1 Time — питч-огибающая осциллятора (щелчок высоты в начале ноты). OSC1 < LFO — вибрато от LFO1. Типичные стартовые значения: Saw — универсальная база (струнные, медь, язычковые), Rect с PW 0.3–0.4 — «нос» (труба, сакс, гармоника), Rect 0.5 — кларнет/орган, Sine — флейта/саб, Noise — дыхание и щелчки (громкость −30…−40 dB).

## Analog: фильтры
F1 Type: Low-pass 12dB/oct, Low-pass 24dB/oct, Band-pass 6dB/oct, Band-pass 12dB/oct, Notch 2-pole, Notch 4-pole, High-pass 12dB/oct, High-pass 24dB/oct, Formant 6dB/oct, Formant 12dB/oct (у Formant резонанс перебирает гласные). F1 Freq — частота (по умолчанию максимум = фильтр открыт): 800 Hz тёмный, 2–3 kHz нейтральный, 6–8 kHz ярко. F1 Resonance (0…1): до 0.15 без пика, 0.3–0.5 заметный пик, выше 0.7 свист. F1 Drive: Off, Sym1–3, Asym1–3 (симметричное/асимметричное насыщение перед фильтром). F1 Freq < Key (−1…1) — слежение за нотой (1.0 = 1:1), F1 Freq < Env — глубина огибающей FEG1 (чем больше, тем сильнее «открытие»), F1 Freq < LFO — модуляция LFO1, F1 Res < Env/LFO/Key — модуляция резонанса. F2 устроен так же. Для вычитающего звучания: всегда задавайте F1 Freq явно — иначе фильтр открыт полностью и звук «пищит».

## Analog: огибающие
FEG1 (фильтр) и AEG1 (усилитель): Attack, Decay, Sustain, S Time (время спада на уровне сустейна: 1.0 — звук держится бесконечно, меньше — медленно затухает), Rel. У параметров 0…1 время нелинейно (экспонента), поэтому задавайте display-значения: «1 ms», «28 ms», «600 ms», «1.4 s». Sustain в Analog нужно ставить явно: по умолчанию 0 (нота затухает до нуля за Decay) — для удерживаемого звука Sustain = 1.0 (norm). Опции: Exp (экспонента вместо линейной), Loop (Off, AD-R, ADR-R, ADS-AR), Free (огибающая не прерывается Note Off), Legato (при легато не перезапускается), A < Vel (velocity укорачивает атаку), < Vel (velocity меняет глубину). AMP1 Level и AMP1 < Key / < LFO — громкость и её зависимость от высоты/LFO (тремоло). Для щипка: AEG1 Attack 1 ms, Decay 0.2–1.5 s, Sustain 0.

## Analog: LFO, вибрато, Unison, клавиатура
LFO1/LFO2: On/Off, Shape (Sine, Tri, Rect, Noise1, Noise2), Sync (Hertz/Beat), LFO1 Speed (0…1) или SncRate, Delay, Fade In, Retrig, Phase. Назначение — через слайдеры целей (OSC1 < LFO, F1 Freq < LFO, AMP1 < LFO, A1 Pan < LFO). Отдельный вибрато-блок: Vib On/Off, Vib Amount, Vib Speed (около 5–6 Hz), Vib Delay, Vib Fade-In, Vib Error (случайность), Vib < ModWh — вибрато «как у исполнителя» включайте с задержкой 300–500 ms. Unison On/Off, Unison Voices (2 или 4), Unison Detune, Unison Delay: размножение голоса для пэдов/струнной секции/медной группы; для солиста не включать. Voices — полифония (Mono, 2…32). Glide On/Off, Glide Time, Glide Mode (Const/Prop), Glide Legato. Key Stretch (0.5 = равномерный строй), Key Error (случайный строй каждой ноты — небольшая «живость»). Noise On/Off: Noise Level, Noise Color (яркость), Noise Balance.
