# Compressor и Glue Compressor (Live 11.3.25)
keywords: compressor, компрессор, glue compressor, глю, сжатие, dynamics, динамика, threshold, порог, ratio, рейшио, attack, release, knee, makeup, sustain, панч, punch, выровнять, склеить, sidechain, сайдчейн, parallel, параллельная компрессия

## Compressor: параметры
Compressor снижает громкость сигнала выше Threshold (dB) в Ratio раз (display «4:1»; 1:1 — ничего, ∞:1 — лимитер). Attack — время, за которое компрессия «включается» (display в ms: короткий 0.5–5 ms прижимает удар; 10–30 ms пропускает атаку — «панч»), Release — время возврата (50–150 ms быстро/пампинг, 200–400 ms музыкально); Auto Release On/Off подбирает его сам. Knee (0…18 dB): 0 — жёсткое колено, 6 dB — мягкое по умолчанию, 10–18 — незаметная компрессия. Model: Peak (реагирует на пики), RMS (по средней громкости, мягче), Expand (расширитель). Env Mode: Lin или Log. LookAhead: 0 ms, 1 ms, 10 ms (опережение для лимитинга). Makeup = On — автоматическая подтяжка уровня; Output Gain (−36…36 dB) — ручная. Dry/Wet — параллельная компрессия: при 30–70 % сохраняет удар и добавляет плотность. S/C On, S/C Gain, S/C EQ — внешний сайдчейн.

## Compressor: типовые настройки
Выровнять акустический инструмент (гитара, баян): Model RMS или Peak, Ratio 2:1–3:1, Threshold так, чтобы «Gain Reduction» показывал 1–3 dB, Attack 10–20 ms, Release 100–150 ms, Knee 6 dB. Укрепить бас: Ratio 4:1, Attack 20–30 ms (чтобы атака прошла), Release 80–150 ms, GR 3–5 dB. Прижать барабанный бас: Ratio 4:1, Attack 5–10 ms. Параллельная «густота»: Ratio 8:1–10:1, Attack 1–3 ms, Release 60–100 ms, Dry/Wet 30–50 %, GR 8–12 dB. Сайдчейн-пампинг (EDM): Ratio ∞ или 10:1, S/C On с кик-источником, Attack 0.01–1 ms, Release 80–150 ms. Правило: сжатие больше 6 dB заметно меняет звук; для «живого» результата достаточно 1–4 dB. Не используйте компрессор, чтобы «починить» плохой синтезный тембр — он усилит шум и хвосты. Для выравнивания уровня до эффектов часто достаточно уровня Volume.

## Glue Compressor: параметры
Glue Compressor — компрессор «шины» в духе аналогового SSL. Параметры со ступенями: Attack (0…6): значения 0.01, 0.1, 0.3, 1, 3, 10, 30 ms; Release (0…6): 0.1, 0.2, 0.4, 0.6, 0.8, 1.2 s и Auto (последняя ступень); Ratio (0…2): 2, 4, 10 (ступени проверяйте в интерфейсе; в API имя значения может быть числом). Threshold (−40…0 dB), Makeup (0…20 dB), Range (0…70 в API; ограничивает максимум сжатия — маленький Range = мягкое «приглаживание», 70 = без ограничения), Dry/Wet (0…1), Peak Clip In (мягкий клиппер на выходе, ≈−0.5 dB; выключен по умолчанию), S/C On/Gain/EQ — сайдчейн. Типично для склейки: Ratio 2 или 4, Attack 10 ms (или 30 ms при ударных), Release 0.2–0.4 s или Auto, Threshold так, чтобы GR был 1–3 dB, Dry/Wet 100 % (или 50 % для параллели).

## Compressor: когда не нужен
Не ставьте компрессор на каждый звук: синтезированные пэды и пады уже ровные по уровню. Щипковые и ударные инструменты с естественным затуханием (гитара, арфа) лучше только слегка (GR 1–2 dB), иначе «насос» убирает жизнь. Соло-язычковые (баян, гармоника) обычно не сжимают сильно — их уровень постоянен. Если после компрессора звук стал «плоским», а не плотным — поднимите Attack (пропустить удар), уменьшите Ratio или Dry/Wet. Если громкость скачет — проверьте Release: слишком короткий вызывает пампинг на басовых нотах. Не забывайте компенсировать Makeup, иначе сравнение «до/после» обманчиво (громче всегда кажется лучше).
