# Ableton Helper: как это работает и диагностика

## Как это устроено
Ableton Helper состоит из трёх частей:
1. **Remote Script** `AbletonHelper` внутри Live (управляющая поверхность, Control Surface). Он слушает локальный порт моста **127.0.0.1:9888** и выполняет команды в Live: создать дорожку, загрузить устройство, поменять параметр.
2. **Локальный сервер** (`abhelper serve`) на **127.0.0.1:8765**: чат, агент на базе Claude, база знаний.
3. **Чат** в браузере (http://127.0.0.1:8765) или в Max for Live-устройстве (окно `jweb`).
Всё работает только на вашем компьютере (127.0.0.1). В интернет уходят только запросы к языковой модели Anthropic.

## Индикаторы в шапке чата
- **Live (зелёный)** — мост подключён; при наведении видны версии Live и Remote Script.
- **Live (красный)** — Remote Script не включён или Live не запущен.
- **AI (зелёный)** — API-ключ настроен.
- **AI (жёлтый)** — не задан ключ: откройте шестерёнку и вставьте ключ с console.anthropic.com.

## Как включить Remote Script
1. Установите скрипт: `python scripts/install_remote_script.py` (по умолчанию в папку Remote Scripts пользовательской библиотеки).
2. Полностью перезапустите Live.
3. Откройте Settings (в Live 11 — Preferences) → **Link, Tempo & MIDI**.
4. В одном из слотов **Control Surface** выберите **AbletonHelper**. Input/Output оставьте None.
5. В строке состояния Live не должно быть ошибок; в чате индикатор Live станет зелёным.
Структура папки должна быть: `Remote Scripts/AbletonHelper/__init__.py` (без лишней вложенности).
Если скрипт не появился в списке, смотрите «Если скрипта нет в списке» ниже.

## Диагностика: `abhelper doctor`
Команда `abhelper doctor` проверяет типичные причины проблем (установлен ли Remote Script, доступен ли мост к Live, настроен ли ключ, свободны ли порты) и подсказывает, что исправить. Запустите её в терминале при любой проблеме и приложите вывод, если обращаетесь за помощью.

## Если скрипта нет в списке Control Surface
- Проверьте путь: `Remote Scripts/AbletonHelper/__init__.py`.
- Перезапустите Live целиком (не только проект).
- Загляните в **Log.txt** (macOS: `~/Library/Preferences/Ableton/Live <версия>/Log.txt`; Windows: `%APPDATA%\Ableton\Live <версия>\Preferences\Log.txt`) и поищите упоминание AbletonHelper и ошибки Python.
- Установите скрипт в папку приложения: `python scripts/install_remote_script.py --dest <путь>`.

## Чат «не видит» Live
1. Запущен ли `abhelper serve`? Откройте http://127.0.0.1:8765/api/status — должен быть JSON.
2. В Live выбран Control Surface AbletonHelper?
3. Порт 9888 свободен? Если занят, смените порт через переменную `ABHELPER_BRIDGE_PORT` (порты должны совпадать у Remote Script и сервера; подробности в README проекта).
4. Антивирус/брандмауэр иногда блокирует даже localhost: разрешите соединения Python и Live на 127.0.0.1.
5. Попробуйте `abhelper serve --fake`: чат заработает с эмулятором Live, тогда проблема именно в мосте.

## Чат не отвечает
- **«Не настроен AI»**: введите API-ключ в настройках или задайте переменную `ANTHROPIC_API_KEY`.
- **Ошибка языковой модели**: проверьте интернет и баланс на console.anthropic.com; попробуйте другую модель в настройках.
- **Белый экран в окне M4L**: сервер не запущен либо другой порт; нажмите «Обновить» на устройстве. Запасной вариант — браузер.

## Некоторые параметры не применились
Названия параметров в разных версиях Live отличаются. Команда `abhelper calibrate` считывает реальные параметры устройств из вашего Live и улучшает рецепты звуков. Ассистент также может сам прочитать параметры устройства и подправить их.

## Что умеет и не умеет ассистент
- Создаёт MIDI-дорожку, подбирает пресет или собирает звук из нативных устройств, добавляет эффекты и демо-клип.
- Звуки акустических инструментов он **приближает** синтезом; качество пресетов зависит от ваших паков.
- Он может отвечать на вопросы «как сделать X в Ableton» по встроенной базе знаний.
- Действия в Live можно отменить: просите «отмени» либо жмите Cmd/Ctrl+Z.

## Частые вопросы
**Нужен ли интернет?** Для работы языковой модели — да. Сам мост и сервер работают локально.
**Сколько это стоит?** Оплата — по тарифам Anthropic за использование API; ассистент ничего не продаёт.
**Можно ли использовать без Live?** Да, `abhelper serve --fake` запускает чат с эмулятором Live (для проверки).
**Безопасно ли это?** Сервер и мост слушают только 127.0.0.1; ключ API хранится локально в `~/.ableton-helper/config.json`.
**Как удалить Remote Script?** `python scripts/install_remote_script.py --uninstall`.
