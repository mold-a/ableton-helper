# Проекты, сохранение и Collect All and Save

## Live Set и папка проекта
- **Live Set** — файл `.als` (сессия/аранжировка). Его сохраняют сочетанием **Cmd/Ctrl+S**, «Save Live Set As…» — **Cmd/Ctrl+Shift+S**.
- Рядом с `.als` лежит папка проекта (Project), в которой Live хранит: **Samples/Recorded** (записанное), **Samples/Imported** (импортированные при сборке), **Presets**, **Ableton Project Info** и другие служебные файлы, а также резервные копии (**Backup**).
- Проект переносим, если все используемые сэмплы лежат внутри папки проекта.

## Collect All and Save
Команда **File → Collect All and Save** (или «Manage Files» → Collect and Save) копирует в папку проекта все внешние сэмплы и пресеты, на которые ссылается Live Set. После неё проект можно архивировать и переносить.
Порядок действий:
1. Откройте проект.
2. Выберите **File → Collect All and Save**.
3. В диалоге отметьте типы файлов для сбора (сэмплы из User Library, внешние папки и т. п.) и подтвердите.
4. Дождитесь окончания: Live скопирует файлы и пересохранит `.als`.
Если вы не хотите дублировать общие библиотеки, оставьте галочки только для действительно нужных категорий.

## Manage Files
Раздел **File → Manage Files** показывает статус проекта и позволяет:
- найти **Missing Files** (потерянные файлы) и указать новое место (Locate/Relocate);
- найти неиспользуемые файлы и удалить их (**Unused Files**);
- собрать внешние файлы.
Если при открытии проекта видите красные клипы или предупреждения «файл не найден», откройте Manage Files и найдите их вручную.

## Резервные копии и восстановление
- Live сохраняет резервные копии предыдущих сохранений в папке `Backup` внутри проекта. Откройте нужный файл `.als` вручную при необходимости.
- После аварийного завершения Live при следующем запуске может предложить восстановить несохранённую сессию (Crash Recovery).
- Периодически используйте «Save Live Set As…» с новым номером версии (проект_v1, проект_v2) — это самый надёжный способ откатиться.

## Шаблоны и сет по умолчанию
- **Template** — набор дорожек, эффектов и клипов, с которого удобно начинать. Сохраните сет и переименуйте как шаблон (**File → Save Live Set as Template…**, если в вашей версии есть такой пункт).
- Сет по умолчанию, открывающийся при запуске Live, настраивается в Settings/Preferences (раздел Library или File Folder; зависит от версии) через «Save Current Set as Default».

## Работа с проектами
- **Open Recent Set** — недавние проекты в меню File.
- Live работает с одним сетом за раз: чтобы открыть другой, используйте File → Open Live Set.
- Чтобы перенести клипы между проектами: «Import» из Current Project либо перетащите клипы через Places (Add Folder).

## Перенос проекта на другой компьютер
1. На исходном компьютере: Collect All and Save.
2. Скопируйте всю папку проекта целиком.
3. На целевом компьютере установите те же плагины (VST/AU) и паки; без них часть устройств будет отмечена как отсутствующие.
4. Откройте `.als`. Если Live просит найти файлы, укажите место в Manage Files.

## Имя и версия Live
Проекты, сохранённые в новой версии Live, могут не открываться в старой. Live 12 может открыть проекты Live 11, но не наоборот (если автор сохранил в Live 12). Держите резервные копии до обновления Live.

## Частые вопросы
**Что делает Collect All and Save?** Копирует внешние сэмплы в папку проекта и пересохраняет сет.
**Как найти потерянные файлы?** File → Manage Files → Missing Files.
**Как восстановить проект после вылета?** Откройте Live: он может предложить восстановление; либо возьмите копию из папки Backup.
**Как уменьшить размер проекта?** Manage Files → Unused Files (удалить неиспользуемое); замораживать только необходимое.
**Можно ли хранить проект в облаке?** Да, но закрывайте Live перед синхронизацией и избегайте одновременной работы с двух компьютеров.

## Практические советы
- Сохраняйтесь регулярно (Cmd/Ctrl+S) и пользуйтесь версиями («проект_v2»).
- Давайте дорожкам и клипам понятные имена и цвета — это экономит время.
- Не храните проект на съёмном диске без резервной копии.
- Перед обновлением Live сделайте копию папки проектов.
- Проверьте, что сторонние плагины совпадают по версиям на разных компьютерах.
- Для совместной работы передавайте папку проекта целиком после Collect All and Save.
- Раз в какое-то время чистите Unused Files, чтобы папка не росла.
