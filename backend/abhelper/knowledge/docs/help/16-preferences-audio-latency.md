# Настройки (Preferences/Settings): аудио, задержка, буфер, CPU
keywords: настройки, preferences, settings, audio, аудио настройки, аудиокарта, audio device, driver, asio, coreaudio, mme, directx, buffer size, размер буфера, latency, задержка, sample rate, частота дискретизации, input config, output config, cpu, процессор, multicore, reduced latency, delay compensation, asio4all, звуковая карта не определяется, нет звука

## Где открыть настройки
- **macOS**: меню **Live → Settings…** (в Live 11 — Preferences…), сочетание **Cmd+,**.
- **Windows**: меню **Options → Settings…** (в Live 11 — Preferences…), также **Ctrl+,**.
Название «Settings» используется в Live 12; в Live 11 это «Preferences».

## Вкладка Audio
- **Driver Type**: на Windows — **ASIO** (рекомендуется), на macOS — **CoreAudio**. Драйверы MME/DirectX дают большую задержку и подходят лишь как запасной вариант.
- **Audio Input Device / Audio Output Device**: выберите вашу звуковую карту.
- **Sample Rate**: 44100 или 48000 Гц (выбирайте единый для проекта; при несовпадении возможны проблемы).
- **Buffer Size**: размер буфера. Меньший буфер = меньше задержка, но выше нагрузка на CPU и риск «потрескиваний». Типично 128–256 сэмплов для записи/игры и 512–1024 для сведения.
- **Input Config / Output Config**: включите нужные входы/выходы (моно/стерео).
- В разделе приводится **Overall Latency** — суммарная задержка в миллисекундах.

## Windows: ASIO4ALL
Если у вашей звуковой карты нет собственного ASIO-драйвера, используйте универсальный драйвер ASIO4ALL (сторонний). Если вы слышите потрескивание, увеличьте буфер или закройте другие приложения.

## macOS: специфика
- Выберите CoreAudio и своё устройство.
- Если Live не слышит новую звуковую карту, проверьте «Audio MIDI Setup» и разрешения на микрофон (Системные настройки → Конфиденциальность).
- Для Apple Silicon используйте актуальную версию Live, нативную для вашего Mac; старые плагины могут работать в режиме Rosetta.

## Задержка (Latency)
- **Рабочее правило**: при записи — маленький буфер; при сведении — большой.
- **Reduced Latency When Monitoring** (меню Options): уменьшает задержку мониторинга, но отключает часть компенсации задержек плагинов.
- **Delay Compensation** (меню Options): выравнивает задержку плагинов. Для записи с минимальной задержкой её иногда отключают, но потом включают обратно.
- **Driver Error Compensation** (Audio): ручная поправка, если записанные дорожки смещены относительно метронома. Подгоняют, записывая клик и сдвигая значение.

## Нагрузка CPU
- Индикатор в Control Bar показывает загрузку (справа вверху).
- **Multicore/Multiprocessor Support** (вкладка CPU): включите, чтобы использовать все ядра.
- Уменьшите нагрузку: Freeze Track, больший буфер, меньше «тяжёлых» плагинов (см. «Типичные проблемы»).
- «Plug-in Latency» и Auto-Warp тоже могут ощутимо нагружать систему.

## Вкладка Record/Warp/Launch
Здесь задаются поведение записи, длина новых клипов, Count-In, автопрогрев Warp и режимы запуска клипов (см. «Warp» и «Запись»).

## Вкладка Link, Tempo & MIDI
Здесь настраиваются MIDI-порты, Control Surface, Takeover Mode и Ableton Link. Подробнее: «MIDI-контроллеры и маппинг».

## Вкладка Library / File Folder
Места хранения: User Library, временная папка, папка проектов; здесь же задают место для плагинов (см. «Типичные проблемы» про VST3).
Названия вкладок немного отличаются в Live 11 и 12; если нужной вкладки нет, используйте поиск по настройкам или просмотрите разделы списка слева.

## Частые вопросы
**Какой буфер выбрать?** 128–256 при записи, 512–1024 при сведении; увеличивайте при потрескиваниях.
**Какую частоту выбрать?** 44.1 или 48 кГц; единую для карты и проекта.
**Почему Live не видит мою звуковую карту?** Установите драйвер производителя, выберите ASIO/CoreAudio, перезапустите Live.
**Как сменить тему оформления?** Settings (Preferences) → Look/Feel.
**Где находится Log.txt?** macOS: `~/Library/Preferences/Ableton/Live <версия>/Log.txt`; Windows: `%APPDATA%\Ableton\Live <версия>\Preferences\Log.txt`.
**Как сбросить настройки Live?** Закройте Live и переименуйте папку настроек (Preferences) — Live создаст новую; сохраните копию для отката.

## Практические советы
- Меняйте одну настройку за раз и проверяйте результат.
- После смены звуковой карты перезапустите Live.
- Если звук «пропадает» только при записи, уменьшите число включённых входов в Input Config.
- Отключите системные звуки и лишние программы на время работы.
- На ноутбуках подключайте питание и выключайте энергосбережение.
- Для USB-карт избегайте USB-хабов.
- Следите за обновлением драйверов и Live.
