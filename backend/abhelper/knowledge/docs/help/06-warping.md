# Warp: растяжение аудио, режимы и Warp-маркеры

## Что такое Warp
**Warp** — это растяжение/сжатие аудио по времени, чтобы сэмпл подстраивался под темп проекта (Tempo) без изменения высоты звука. Включается в Clip View для аудиоклипа.

## Как включить Warp у сэмпла
1. Дважды щёлкните по аудиоклипу — откроется **Clip View** (вкладка Sample).
2. Нажмите кнопку **Warp** (она светится жёлтым/оранжевым при включении).
3. Выберите **Warp Mode** в выпадающем списке (см. ниже).
4. Проверьте поле **Seg. BPM**: это определённый темп сэмпла. Кнопки **/2** и **×2** исправляют ошибку «вдвое быстрее/медленнее».
Если Live неправильно определил темп, поправьте число вручную или перетащите Warp-маркеры.
Auto-warp длинных сэмплов включается в Settings → Record/Warp/Launch (параметр «Auto-Warp Long Samples»), короткие обычно загружаются без warp.

## Режимы Warp
- **Beats** — для ритмичного материала (ударные, лупы): сохраняет транзиенты. Настройки Preserve (1/8, 1/16 и т. д.), Loop Mode, Transient Envelope.
- **Tones** — для материала с чётким тоном (бас, вокал, моносинт): параметры Grain Size.
- **Texture** — для шумов, текстур, атмосфер: параметры Grain Size, Flux.
- **Re-Pitch** — меняет высоту вместе со скоростью, как проигрыватель винила или лента; не растягивает «чисто». Хорош для творческих эффектов.
- **Complex** — для готовых миксов, полифонии; качественно, но ощутимо нагружает процессор.
- **Complex Pro** — улучшенная версия Complex; есть настройки Formants и Envelope; ещё тяжелее.
Выбор режима зависит от материала. Если слышны артефакты, попробуйте другой режим.

## Warp-маркеры (Warp Markers)
- Маркеры привязывают точки аудио к положению на сетке.
- Двойной щелчок по заголовку маркерной полоски создаёт маркер; перетаскивание сдвигает.
- Правый клик по маркеру: «Warp From Here» (с указанием размера), «Set 1.1.1 Here» (установить начало), «Warp as N Bars» (подогнать под N тактов).
- Чтобы удалить: выделить и Delete.
- Для длинных треков: «Warp From Here (Straight)» ставит однородное растяжение, «Warp From Here» пытается определить темп автоматически.

## Транспонирование (Pitch)
- Параметры **Transpose** (полутона) и **Detune** (центы) меняют высоту, не меняя длительность (при включённом Warp).
- Для зацикливания и «слайсов» используйте Loop и Start/End.

## Следование темпу проекта
При включённом Warp сэмпл «следует» темпу проекта: изменили Tempo — клип подстроился. Без Warp клип играет с исходной скоростью.
Если нужно, чтобы клип играл оригинально, но в одном такте, отключите Warp.

## Warp в Live 11 и Live 12
Режимы и логика одинаковы. В Live 12 интерфейс Clip View слегка переработан, но Warp, Seg. BPM, Warp-маркеры и режимы в тех же местах.

## Типичные проблемы
- **Клип звучит «водянисто»**: смените режим на Complex/Complex Pro, либо уменьшите степень растяжения.
- **Темп определён неверно**: используйте /2 и ×2; если не помогает, укажите Seg. BPM вручную.
- **Сэмпл-лупы «плывут»**: включите Warp и проверьте начало и конец клипа (Start/End, Loop).

## Частые вопросы
**Как узнать темп сэмпла?** Включите Warp и посмотрите Seg. BPM в Clip View.
**Как зациклить сэмпл ровно в такт?** Включите Loop, поставьте Start/End на границы такта (Warp-маркеры помогают), включите Warp.
**Как поменять высоту без изменения темпа?** Warp включён → параметр Transpose/Detune.
**Как менять темп без изменения высоты?** Warp включён, меняйте Tempo проекта.
**Как нарезать сэмпл на куски?** В Simpler выберите режим Slicing или правый клик по клипу → «Slice to New MIDI Track» (название может отличаться).
**Как отключить Warp?** Нажмите кнопку Warp в Clip View ещё раз.
**Warp тянет «ударные» плохо.** Включите режим Beats и поставьте Preserve на 1/16 либо подправьте Warp-маркеры вручную.
**Warp для вокала?** Обычно Complex или Complex Pro (с Formants), для монофонического — Tones.

## Практические советы
- Сначала проверьте, что сэмпл действительно нужно растягивать: короткие one-shot обычно играют без Warp.
- Для зацикленных барабанных лупов Beats с Preserve 1/16 — самое быстрое решение.
- Для вокала и акапелл попробуйте Complex Pro и подберите Formants.
- Чтобы изменить «чувство» (groove), используйте Groove Pool, а не растяжение.
- Сохраняйте настройки Warp по умолчанию для клипа кнопкой «Save» (в Clip View).
