# Экспорт, Freeze, Flatten, Consolidate и ресемплинг

## Экспорт аудио (Export Audio/Video)
1. Выделите нужный диапазон в Arrangement (или не выделяйте — тогда экспортируется весь проект) либо установите петлю.
2. Нажмите **Cmd/Ctrl+Shift+R** (File → Export Audio/Video).
3. Параметры в диалоге:
   - **Rendered Track**: Master (общий микс), All Individual Tracks (стемы), либо выбранные дорожки/возвраты.
   - **Render Start / Render Length**: границы рендера.
   - **Include Return and Master Effects**: включать ли эффекты возвратов и мастера для отдельных дорожек.
   - **Normalize**: нормализовать пик до 0 dB (обычно не нужно, если вы готовите трек к мастерингу).
   - **Render as Loop**: рендер с «хвостом» для зацикливания.
   - **Convert to Mono**: для моно-файлов.
   - **File Type**: WAV, AIFF, FLAC, MP3 (набор может зависеть от версии).
   - **Sample Rate** и **Bit Depth**: 44.1/48 kHz, 16/24/32-bit (для рабочих файлов обычно 24-bit; для финальных — по требованиям площадки).
   - **Dither Options**: нужен при уменьшении до 16 бит.
4. Нажмите Export и выберите папку.
Экспорт идёт быстрее реального времени (офлайн), но плагины с задержкой могут увеличить время.

## Экспорт MIDI
Правый клик по MIDI-клипу → **Export MIDI Clip…** сохраняет файл .mid.

## Freeze (заморозка)
Freeze рендерит дорожку вместе с эффектами во временный аудиофайл, чтобы снизить нагрузку на CPU.
1. Правый клик по заголовку дорожки (или клипу) → **Freeze Track**.
2. Дорожка станет «замороженной» (снежинка); параметры нельзя менять.
3. Чтобы снова править: правый клик → **Unfreeze Track**.
Заморозка помогает при перегрузке CPU и «тяжёлых» VST. Заморозка не изменяет проект навсегда.

## Flatten (сведение заморозки)
После Freeze пункт **Flatten** превращает замороженную дорожку в обычный аудиоклип; исходные устройства и MIDI-ноты при этом заменяются аудио. Это необратимо (используйте Undo сразу), поэтому сохраните копию проекта. Правый клик → Flatten.

## Consolidate (объединение клипов)
Выделите несколько клипов на одной дорожке в Arrangement и нажмите **Cmd/Ctrl+J** — они объединятся в один клип (аудио будет отрендерено в файл).

## Resampling (ресемплинг)
Чтобы записать результат обработки в аудио:
1. Создайте аудиодорожку.
2. В «Audio From» выберите **Resampling**.
3. Включите arm и запишите нужный фрагмент.
Так можно превратить MIDI-партию с эффектами в аудио для дальнейшей нарезки и обработки.

## Стемы (Stems)
Для отправки стемов: **Rendered Track = All Individual Tracks** либо выбирайте группы. Не забудьте, что реверб/дилей с возвратов тоже нужно экспортировать (отдельно или включив «Include Return and Master Effects»).

## Частые вопросы
- **Экспортированный файл тише, чем в Live**: нормализация выключена; проверьте Master Limiter и уровни.
- **В экспорте нет эффекта реверб**: возвраты экспортируются отдельно, либо включите опцию.
- **Звук отличается от прослушивания**: проверьте плагины с задержкой (limiter с lookahead) и автоматизацию на последних тактах; прослушайте экспорт ещё раз.

## Чек-лист перед финальным экспортом
1. Проверьте, что на Master нет клиппинга; оставьте запас, если трек пойдёт на мастеринг.
2. Отключите Solo и Mute, которые вы использовали при сведении.
3. Убедитесь, что диапазон экспорта охватывает хвост реверба (добавьте пару секунд в конец).
4. Выберите формат: WAV/AIFF 24-bit для мастеринга, MP3/WAV 16-bit для публикации.
5. Включите Dither при понижении разрядности до 16 бит.
6. Прослушайте готовый файл целиком в другом проигрывателе.
7. Сохраните проект (Cmd/Ctrl+S) и при необходимости Collect All and Save.
8. Если экспорт идёт очень долго, заморозьте тяжёлые дорожки (Freeze Track) и повторите.
9. Для стемов сохраняйте одинаковую длину файлов, чтобы они совпадали при импорте в другую программу.
