# MIDI-контроллеры, MIDI Map и Key Map

## Подключение MIDI-клавиатуры или контроллера
1. Подключите устройство по USB (или MIDI-интерфейсом).
2. Откройте настройки: **Live → Settings (Preferences)** на macOS; **Options → Settings (Preferences)** на Windows. В Live 12 раздел называется Settings, в Live 11 — Preferences.
3. Вкладка **Link, Tempo & MIDI** (в Live 11 — Link/MIDI): в блоке **MIDI Ports** найдите ваш вход.
4. Включите:
   - **Track** для Input — чтобы ноты шли на дорожки;
   - **Remote** — чтобы устройство управляло параметрами (MIDI Map);
   - **Sync** — только для синхронизации (тактовая частота).
5. Включите arm на MIDI-дорожке и играйте.

## Control Surface (поддерживаемые контроллеры)
Для многих контроллеров (Push, APC, Launchpad, Novation, Akai, Native Instruments и др.) в Live есть готовые скрипты. В разделе Link, Tempo & MIDI выберите контроллер в списке **Control Surface** и укажите его порты Input/Output. Если вашего контроллера нет в списке, используйте MIDI Map.

## MIDI Map (ручное назначение)
1. Включите режим **MIDI Map** — кнопка MIDI в правом верхнем углу или **Cmd/Ctrl+M**. Интерфейс подсветится.
2. Кликните параметр в Live (ручку, фейдер, кнопку, переключатель).
3. Подвигайте ручку/нажмите кнопку на контроллере. Назначение появится в списке слева (Mapping Browser).
4. Задайте диапазон Min/Max (для ручек) и режим.
5. Выключите MIDI Map тем же способом.
Через MIDI Map назначают ручки, фейдеры и кнопки контроллера. Клавиши компьютерной клавиатуры назначаются через Key Map (ниже).

## Key Map (назначение клавиш компьютера)
- Режим **Key Map** — кнопка KEY в правом верхнем углу или **Cmd/Ctrl+K**.
- Кликните элемент, затем нажмите клавишу на клавиатуре компьютера. Подходит для запуска клипов, включения кнопок и переключения режимов.

## Takeover Mode (режим подхвата)
Если положение ручки контроллера не совпадает со значением в Live, при первом движении возможен резкий скачок. Takeover Mode в настройках (Link, Tempo & MIDI) решает это: None (скачок), Pickup (пока не «догоните» значение), Value Scaling (плавное сближение).

## Макро и контроллеры
Привяжите ручки контроллера к Macro-регуляторам Rack'а (см. «Устройства и Rack'и»): так вы управляете сразу несколькими параметрами одной ручкой.

## MPE
Если ваш контроллер поддерживает MPE (ROLI Seaboard, Linnstrument и др.), включите режим MPE для входа в MIDI Ports и используйте MPE-совместимые инструменты. См. также «Редактирование MIDI».

## Если контроллер не работает
- Проверьте кабель и драйвер, перезапустите Live.
- Убедитесь, что включены **Track/Remote** для порта.
- Нет звука, но ноты принимаются: нужен инструмент на дорожке и включённый arm (см. «Запись MIDI и аудио»).
- Если один и тот же контроллер работает с другой программой, закройте её: порт может быть занят.
- Для скриптов поверх контроллера (Push) смотрите документацию производителя.

## Частые вопросы
**Как посмотреть, какие параметры уже назначены?** В режиме MIDI Map/Key Map назначения отображаются в списке слева.
**Как удалить назначение?** В режиме Map выберите параметр и нажмите Delete (или правый клик → Remove).
**Работают ли контроллеры одновременно?** Да, можно использовать несколько портов; у каждого свои настройки Track/Remote.
**Как привязать колесо модуляции?** Колесо идёт как MIDI CC1; на MIDI-дорожке оно уже работает с устройствами, которые его поддерживают.
**Как записать движения ручек?** Включите запись автоматизации (Automation Arm) и крутите (см. «Автоматизация»).
**Нужен ли драйвер?** Большинство USB-контроллеров работают без драйвера (class-compliant); иначе установите драйвер производителя.

## Практические советы
- Подписывайте назначения: в режиме MIDI Map Live показывает цвет параметров; запишите, какой ручке что назначено.
- Для лайва привяжите регуляторы к Macro нескольких Rack'ов и держите контроллер в «Remote».
- Если нужна готовая схема для Push или другого устройства, выберите соответствующий Control Surface.
- Сохраняйте настройки: назначения хранятся в проекте (Live Set), а не только в настройках.
- Для шаблонных назначений создайте пустой проект с назначениями и сохраните его как Template.
- Для MIDI-клавиатур с педалью сустейна убедитесь, что порт включён как Track.
- Чтобы временно отключить контроллер, выключите Remote для порта.
