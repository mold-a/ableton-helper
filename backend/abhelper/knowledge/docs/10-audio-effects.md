# Аудиоэффекты Live: EQ, компрессия, реверб, дилей, насыщение

## Эквализация
- **EQ Eight** — параметрический эквалайзер на 8 полос. Есть режимы Stereo, L/R, M/S, встроенный спектроанализатор (кнопка Analyze).
  - Типичное применение: фильтр высоких частот (High Pass) на 30–40 Гц для убирания «грязи», срез резонансов, подъём «воздуха».
- **EQ Three** — простой трёхполосный DJ-EQ.
- **Channel EQ** — быстрый эквалайзер в стиле канала микшера (в новых версиях Live; уточните для вашей).

## Динамика
- **Compressor** — классический компрессор: Threshold, Ratio, Attack, Release, Makeup/Output; есть Sidechain. Режимы Peak/RMS/Expand.
- **Glue Compressor** — «клеящий» компрессор (в стиле SSL), отлично для групп и мастера.
- **Limiter** — ограничитель пиков; обычно последний в цепочке на Master.
- **Multiband Dynamics** — компрессия в разных частотных диапазонах.
- **Gate** — подавляет шум ниже порога.
- **Drum Buss** — пакет для ударных: сатурация, компрессия, усиление баса.
Подробнее про sidechain: тема «Основы микса и sidechain».

## Пространственные эффекты
- **Reverb** — стандартный реверб: Decay, Size, Dry/Wet; подходит для возвратов (Return, 100% wet).
- **Hybrid Reverb** — гибридный (конволюционный + алгоритмический) реверб с множеством пространств. Доступность по редакциям уточните.
- **Delay** — классический дилей (Simple, Ping Pong, Filter Delay).
- **Echo** — современный дилей с модуляцией, фильтрами и «аналоговым» характером; во многом заменяет Delay для творческих задач (в современных версиях Live).
- **Chorus-Ensemble** — хорус/ансамбль; даёт ширину и «хоровой» эффект (важно для мюзета и струнных).
- **Phaser-Flanger**, **Auto Pan/Tremolo** — модуляционные эффекты.

## Искажение и характер
- **Saturator** — мягкое насыщение/перегруз; «тепло» без жёсткого клиппинга.
- **Overdrive**, **Pedal**, **Amp**, **Cabinet** — гитарные овердрайвы и усилители.
- **Roar** — многорежимное сатурирующее устройство с модуляцией (новые версии Live; уточните доступность).
- **Redux** — цифровая деградация (понижение битности/частоты дискретизации).

## Фильтры и утилиты
- **Auto Filter** — фильтр с LFO, огибающей, режимами Low/High/Band/Notch; популярен для свипов.
- **Utility** — громкость, ширина (Width), панорама, инверсия фазы, Mono; обязательно для управления гейном и «ширины».
- **Spectrum** — анализатор спектра для проверки микса.
- **Tuner** — тюнер.
- **Resonators, Vocoder, Frequency Shifter, Corpus** — специальные эффекты.
- **Grain Delay, Beat Repeat** — творческие эффекты.

## Как добавить эффект
1. Выделите дорожку.
2. Двойной клик на эффекте в браузере.
3. Для реверба/дилея лучше использовать Return-дорожку, чтобы один эффект обслуживал много дорожек (см. «Дорожки и роутинг»).
4. Настройте Dry/Wet.

## Что для чего
- **Звук тусклый** → EQ Eight (поднять верха), Saturator.
- **Звук слишком резкий** → EQ Eight (срез в области 2–5 кГц), Compressor.
- **Звук тонкий** → Chorus, Utility (Width), Saturator, добавить октавный слой.
- **Нужно «пространство»** → Reverb/Hybrid Reverb на Return, Echo/Delay.
- **Нужна энергия** → Compressor/Glue, Drum Buss.
Какие эффекты у вас есть, зависит от редакции; смотрите браузер Live → Audio Effects.

## Частые вопросы
**Как сделать звук «шире»?** Utility (Width выше 100%), Chorus-Ensemble, лёгкая стерео-задержка.
**Как «склеить» микс?** Glue Compressor на мастере с мягкими настройками (Ratio 2:1, медленный Attack).
**Как убрать «гул»?** EQ Eight: High Pass около 30–40 Гц.
**Как сделать «телефонный» голос?** EQ Eight: срез низов и верхов, оставить 500–3000 Гц.
**Как быстро сделать «пампинг»?** Sidechain-компрессор (см. «Основы микса и sidechain»).
**Где настраивать Dry/Wet?** У большинства эффектов есть ручка Dry/Wet; у Reverb на Return ставят 100%.
