# Ableton Helper — архитектура

AI-ассистент, встроенный в Ableton Live. Две задачи:

1. **Создание звуков по запросу** (основная): «хочу звук баяна» → в сете появляется
   MIDI-дорожка с настроенным инструментом, эффектами и демо-клипом.
2. **Навигация по Ableton**: ответы на вопросы «как сделать X», с учётом текущего сета.

## Почему не «чистый» плагин (VST/AU)

VST/AU-плагин не имеет доступа к сету Live: он не может создавать дорожки, грузить
устройства из браузера или менять параметры других устройств. Это умеет только
**Live API**, доступный из двух мест:

| Механизм | Доступ к API | Браузер Live (пресеты) | UI внутри Live | Требования |
|---|---|---|---|---|
| MIDI Remote Script (Python) | полный | **да** (`Application.browser.load_item`) | нет | любая редакция Live 11/12 |
| Max for Live (JS LiveAPI) | почти полный | **нет** | да (`jweb`) | Suite или M4L |

Поэтому система гибридная: Remote Script — «руки» внутри Live, Max for Live-устройство —
окно чата внутри Live, а «мозг» (LLM-агент) — отдельный локальный процесс.

## Компоненты

```
│        │                                   ▲ TCP 127.0.0.1:9888
└────────┼───────────────────────────────────┼─────────────────┘
         │ HTTP + SSE                        │ JSON lines (docs/PROTOCOL.md)
┌────────▼───────────────────────────────────┴─────────────────┐
│ backend (python, пакет abhelper)                             │
│  server/   FastAPI: UI, /api/chat (SSE), /api/status         │
│  agent/    цикл tool-use с Claude, системный промпт, tools   │
│  sound/    SoundEngine: библиотека рецептов, поиск пресетов, │

│  knowledge/ база знаний по Ableton + поиск                    │
│  bridge/   клиент TCP-моста + FakeBridge (эмулятор для тестов)│
└──────────────────────────────────────────────────────────────┘
         ▲
         └── ui/ (статический веб-чат; открывается в jweb или в браузере)
```

### 1. `remote_script/AbletonHelper/` — мост в Live
- Control Surface, который пользователь выбирает в Preferences → Link/Tempo/MIDI.
- TCP-сервер на `127.0.0.1:9888`, протокол — `docs/PROTOCOL.md`.
- Сетевой поток только принимает запросы; **все вызовы Live API — в главном потоке**
  (очередь, разбираемая в `update_display()`, ~10 Гц).
- Индекс браузера Live строится инкрементально (по кусочку за тик), чтобы не фризить Live.
- Совместимость: Python 3.7 (Live 11) и 3.11 (Live 12). Без сторонних зависимостей.

### 2. `backend/abhelper/sound/` — звуковой движок
Стратегия создания звука (`strategy="auto"`):
1. **Рецепт** из библиотеки по алиасам RU/EN («баян», «гармонь», «accordion»).
2. **Пресет из браузера Live**: поисковые термины рецепта (или запроса) → `browser_search`
   → ранжирование → `load_browser_item`. Пресет используется, если найден уверенно.
3. **Синтез по рецепту**: нативный инструмент (Operator / Wavetable / Analog / Drift…) +
   параметры + цепочка эффектов. Работает в любой редакции, где есть устройство.
4. **Кастомный рецепт от LLM**: если в библиотеке нет подходящего, модель сама
   составляет рецепт по той же JSON-схеме (`docs/INTERFACES.md`), движок его применяет.
5. Демо-клип (аккорды/мелодия/бас/бит по категории) в первый свободный слот.

Имена параметров устройств отличаются между версиями Live, поэтому движок сопоставляет
их нечётко и **возвращает список непримененных параметров** — агент может прочитать
реальные параметры (`get_device_parameters`) и поправить.

### 3. `backend/abhelper/agent/` — LLM-агент
- Claude API (`anthropic` SDK), ручной цикл tool-use со стримингом.
- Модель по умолчанию `claude-opus-5-5`, `thinking: adaptive`, effort настраивается.
- Инструменты: обзор сета, поиск по библиотеке звуков и браузеру, создание звука,
  кастомный рецепт, чтение/запись параметров, MIDI-клипы, транспорт, undo, справка.

### 4. `backend/abhelper/server/` + `ui/` — интерфейс
- `POST /api/chat` → SSE-поток событий (текст, вызовы инструментов, результат).
- Веб-чат на русском, работает в `jweb` внутри M4L-устройства или в обычном браузере.

### 5. `m4l/` — устройство Max for Live
Компактная полоска в цепочке устройств: статус + кнопка, открывающая плавающее окно
с `jweb` (высота полосы M4L-устройства ~169 px — для чата мало).

## Порты и конфигурация
| Что | По умолчанию | Переопределение |
|---|---|---|
| Мост Remote Script | `127.0.0.1:9888` | `ABHELPER_BRIDGE_PORT` |
| Веб-сервер | `127.0.0.1:8765` | `ABHELPER_PORT` |
| Модель | `claude-opus-5-5` | `ABHELPER_MODEL` |
| API-ключ | `ANTHROPIC_API_KEY` | или `~/.ableton-helper/config.json` |

Всё слушает только `127.0.0.1`.
